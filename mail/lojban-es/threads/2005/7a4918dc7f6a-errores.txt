El error es el siguiente:

> le verba po'u le se sarji ge'u po'u le pindi ge'u

le verba po'u le se sarji ge'u zi'e po'u le pindi ge'u
zi'e noi remoi sumti ku'o ku 

Para usar más de una clausula relativa aplicadas al mismo
sumti es necesario unirlas con {zi'e}.
