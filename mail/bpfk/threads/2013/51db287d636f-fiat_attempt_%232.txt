I would like to define the defaults for {za'u} and {me'i} to be
"contextually specified, usually the current value for the thing
under discussion", rather than {pa}.

Two reasons:

1.  {za'u} and {su'o} mean almost exactly the same thing as
currently defined, similarily {me'i} and {su'e}.  Freaking annoying.

2.  Everybody uses them that way anyways; see {za'u re'u}, which is
very common, and has almost no meaning without this change:
http://corpus.lojban.org/corpus/search/za'ure'u?showall=y and
http://corpus.lojban.org/corpus/search/za'u%20re'u?showall=y

In addition, it would give me a clean way to say "I need more flour
for this cake", or whatever.

-Robin

We finally have an experimental PA for "elliptical/unspecified number":
{xo'e}. I've been saying for a while that {xo'e} would make a much better
default for all of the operator-like-PA than their current hardcoded
values. Perhaps with the note that in most contexts, the obvious value for
{xo'e} would be either {pa} or {ro}, as previously defined. (In the same
way that {ca ku} acts like {ca zo'e}, but the value of {zo'e} is usually
assumed to be "now", except when it's not.)

As far as I know, the default for "me'i" is "ro", not "pa". "me'i ro" =
"not all", is one of the four Aristotelian quantifiers (ro, no, su'o and
me'i). I wouldn't change it.


> Two reasons:
>
> 1.  {za'u} and {su'o} mean almost exactly the same thing as
> currently defined, similarily {me'i} and {su'e}.  Freaking annoying.

They correspond to >, >=, < and <=.



> 2.  Everybody uses them that way anyways; see {za'u re'u}, which is
> very common, and has almost no meaning without this change:
> http://corpus.lojban.org/corpus/search/za'ure'u?showall=y and

>
>
"za'u re'u" means the same as "za'u pa re'u", i.e. "for
other-than-the-first time" = "again".


> In addition, it would give me a clean way to say "I need more flour
> for this cake", or whatever.


 I don't think this is the same as "za'u (some number)". If you already
have three cups of flour, when you say you need "more flour", couldn't you
mean you need one more cup, which is less than what you already have, less
than the current number, not more?
