Now: {cifnu} = x1 is an infant/baby [helpless through youth/incomplete 
development] of species x2. |>>> Also infantile.  See also makcu, verba.

Proposed: {cifnu} = x1 is an infant, baby, young offspring of species x2. 
|>>> Not necessarily helpless. See also makcu, verba, panzi.

Reason: a discussion 
<https://groups.google.com/forum/#!topic/lojban/N5bA5JlhroQ> shows that one 
shouldn't paid attention to "infant", "helpless" and "infantile" words. 
Separate words for "altricial/precocial", stages of development like 
larvae, imago etc. and for immature/mature are to be invented instead.

Technically issue 131 <https://github.com/lojban/jbovlaste/issues/131> says
that no definition can be edited since otherwise the concept of voting
becomes useless.
This means that definitions entered by "officialdata" can't be changed
since this user is not a human. In case  some definitions are already
edited we will be able to reupload them. The issue also states that one
must be able to export all definition from a given user, "officialdata" in
this case.
When JVS API is available we will be able to create apps that are able to
interact with it thus implementing JVS 2.0 as we want it.
