yet another post in English (feel free to find words for "syntactic tree",
"node","level in the syntactic tree", "reset" and "refer to one level up").

Several tools are currently used for moving to other levels of the tree:
1. no'a - shifts one level down
2. lo - shifts one level up
3. ku - shifts one level down
4. vo'a - temporarily resets to level 0 (proposed = {no'axiro})
5. {xoi} (proposed meaning) - temporarily shifts one level up
6. {soi} (proposed meaning) - temporarily resets to level 0
7. {i} - explicitly marks level 0
8. {i'au} (proposed meaning) - resets to level 0


This list is obviously in no way complete.

I think there should be some normalization of these both disparate
proposals and used constructs.
