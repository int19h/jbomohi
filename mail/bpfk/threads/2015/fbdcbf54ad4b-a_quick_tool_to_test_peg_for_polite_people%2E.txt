http://mw.lojban.org/extensions/ilmentufa/mahantufa/ircitufa.html

This is the tool where you can insert your PEG, compile it online and test
it.

Note that if you open this tool and the grammar doesn't work it means
someone else before you ruined it so please paste and compile a fresh one
e.g. from here:
https://raw.githubusercontent.com/Ilmen-vodhr/ilmentufa/master/camxes-exp.js.peg

I already created a copy of it for xorxes so he can continue working with
his own copy, not with this one.

For all the others please be polite and if you ruin the grammar with your
modifications please use Ctrl+Z to restore the initial grammar and then
compile it to save the initial state to the server.

A user-based approach would be nice of course but first we need to think
how to implement that.
