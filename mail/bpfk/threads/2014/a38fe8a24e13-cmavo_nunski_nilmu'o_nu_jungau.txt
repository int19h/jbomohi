[ Translation ]

Hello BPFK members,

I and others almost completed the template harmonization of all the BPFK 
cmavo sections 
<http://www.lojban.org/tiki/tiki-index.php?page=BPFK%20Sections>, so 
that they're (almost) all using the standard template ( 
http://www.lojban.org/tiki/BPFK+Community+Work#Templates ).
Now there remain only the three lerfu pages which are still lacking the 
box template.
The only formatting things that may be problematic and that I can think 
of are that there probably remain cmavo descriptions lacking the "See 
Also" and "Proposed Keywords" fields, as well as See Also sections 
lacking curly brackets {} around word links.
Furthermore most sections lack the "Proposed Tag" field (whose purpose I 
still don't know).

Now the cmavo section that seems most incomplete is this one: 
http://www.lojban.org/tiki/BPFK+Section%3A+Attitudinal+Modifiers
It contains many incomplete definitions.

I hope you'll appreciate the work we've done so far. :)

Ilmen.
