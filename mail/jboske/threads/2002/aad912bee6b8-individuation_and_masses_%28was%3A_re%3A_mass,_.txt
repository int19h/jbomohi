Countability. "How many beers [drinks] have you had?" "How many beers
[vats] are in this cellar?" "How many beers [cans] are in the fridge?"
All these questions make sense and thus want "xu lo birje".

{xo lo birje}, yes, we all agree about that.



Where counting does not make sense, then "loi birje" is appropriate.

{lo birje} can also be appropriate in some of those cases.
{le botpi cu vasru lo birje}, "the bottle contains some amount
of beer".

Sometimes we do need counting with the collective sense:
{oi mi na ka'e bevri lei bi birje}, "I can't carry the 8 beers!"
I could carry each of them, but not the eight as a whole.

I can agree with that. But gadri are not supposed to be
predications on the referents of the term, but rather different
ways of referring to the same objects. For the same set of
referents {le'i broda} I can make two claims {le broda cu brode
ije lei broda cu brodi}. The objects described are the same, the
gadri only indicates how they enter into the relationship.

fill the bowl". I describe the same objects with different gadri
because they enter each relationship differently.

be used to describe different objects, so it is a distinction to
be made by using different selbri. There is no "apple stuff" that
corresponds directly to the set of seven apples, so if we were
to have a substance gadri it would not be related to the set in
the way other gadri work.
