The idea of using retu'o for twentysomething is interesting, but not
necessary, since reji'imu expresses exactly the same thing, and more
flexibly too (thus reji'ino would be 15-25, ancient Roman adolescence).

So tu'o should remain zi'o-like; it expresses that there is no number here.
