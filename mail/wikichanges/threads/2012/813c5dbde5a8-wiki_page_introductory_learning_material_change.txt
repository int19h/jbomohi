!Books

* Pre-introductory is Jay's ((Jay's Lojban Brochure)).

* People who send a postcard to the LLG receive the ((Level -1 flyer)).

* For a more detailed introduction, please see ((Nick Nicholas)) and ((John Cowan))'s ''[http://lojban.org/publications/level0.html|What is Lojban?]'', which has become the ((Level 0 Booklet)) for ((The Logical Language Group)), and is available from [http://www.amazon.com/exec/obidos/tg/detail/-/0966028317/qid=1062895255/sr=8-1/ref=sr_8_1/102-4826386-3031311?v=glance&s=books&n=507846|Amazon Books]. There is an incomplete PDF of [http://www.lojban.org/tiki/tiki-download_wiki_attachment.php?attId=89|the first 19 pages of the Level 0 Booklet], a project in progress, which typesets and illustrates the diagrams with nested tables.

* Next there is ''[http://ptolemy.tlg.uci.edu/~opoudjis/lojbanbrochure/lessons/book1.html|Lojban For Beginners]'' (the "((lessons))"), by ((Robin Turner)) and Nick Nicholas, currently being edited by Nick Nicholas.

** Robin Turner wrote [http://www.bilkent.edu.tr/~robin/lojbancourse.html|some lessons], but they were used as the basis for the above ''Lojban For Beginners'', which is more complete.

* Finally, the '''ultimate''' educational resource is the canonical text ((The Complete Lojban Language)), available in paper from the ((The Logical Language Group)), or in draft form [http://lojban.org/publications/reference_grammar.html|on line].

----

* A ((phrasebook)) is being compiled.

* ((Multimedia)) and other materials which aren't purely textual (sound recordings)

* ((.i tavla fi la lojban ri)), an in-progress list of easy-to-use vocabulary intended to facilitate talking about Lojban in Lojban.

* There is a [http://www.lojban.org/files/roadmap.html#draft-textbook|draft textbook] by ((BPFK Member: Bob LeChevalier)), which hasn't been updated in a very long time.

----

!Books

* Pre-introductory is Jay's ((Jay's Lojban Brochure)).

* People who send a postcard to the LLG receive the ((Level -1 flyer)).

* For a more detailed introduction, please see ((Nick Nicholas)) and ((John Cowan))'s ''[http://lojban.org/publications/level0.html|What is Lojban?]'', which has become the ((Level 0 Booklet)) for ((The Logical Language Group)), and is available from [http://www.amazon.com/exec/obidos/tg/detail/-/0966028317/qid=1062895255/sr=8-1/ref=sr_8_1/102-4826386-3031311?v=glance&s=books&n=507846|Amazon Books]. There is an incomplete PDF of [http://www.lojban.org/tiki/tiki-download_wiki_attachment.php?attId=89|the first 19 pages of the Level 0 Booklet], a project in progress, which typesets and illustrates the diagrams with nested tables.

* Next there is ''[http://ptolemy.tlg.uci.edu/~opoudjis/lojbanbrochure/lessons/book1.html|Lojban For Beginners]'' (the "((lessons))"), by ((Robin Turner)) and Nick Nicholas, currently being edited by Nick Nicholas.

** Robin Turner wrote [http://www.bilkent.edu.tr/~robin/lojbancourse.html|some lessons], but they were used as the basis for the above ''Lojban For Beginners'', which is more complete.

* Finally, the '''ultimate''' educational resource is the canonical text ((The Complete Lojban Language)), available in paper from the ((The Logical Language Group)), or in draft form [http://lojban.org/publications/reference_grammar.html|on line].

* ((Multimedia)) and other materials which aren't purely textual (sound recordings)

* ((.i tavla fi la lojban ri)), an in-progress list of easy-to-use vocabulary intended to facilitate talking about Lojban in Lojban.

* There is a [http://www.lojban.org/files/roadmap.html#draft-textbook|draft textbook] by ((BPFK Member: Bob LeChevalier)), which hasn't been updated in a very long time.
