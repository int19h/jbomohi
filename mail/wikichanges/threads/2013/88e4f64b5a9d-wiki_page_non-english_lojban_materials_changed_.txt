!Lojbanic Information Not In English Or Lojban



!! Mailing Lists and Groups

* There is now a [http://groups.google.com/group/lojban-pl/|Polish Lojban Google Group].

*There is now a [http://groups.google.com/group/lojban-soudan/|Japanese Lojban Google Group].

* There is now a [http://www.lojban.org/lists/lojban-es/|Spanish Lojban mailing list], which you can sign up for using [http://www.lojban.org/lsg2/|the mailing list web interface].

* There is now a [http://www.lojban.org/lists/lojban-fr/|French Lojban mailing list], which you can sign up for using [http://www.lojban.org/lsg2/|the mailing list web interface].

* Otherwise, just ask on the [http://www.lojban.org/lsg2|lojban mailing list].



!!The Lojban Brochure

There are versions of the introductory [http://www.lojban.org/publications/brochures/brochure_english.txt|brochure] (soon to be superseded by the version in the new ((What is Lojban?, The Book)) ) in various languages.



* [http://www.lojban.org/publications/brochures/brochure_espanol.txt|Spanish Brochure]

* [http://www.lojban.org/publications/brochures/brochure_esperanto.html|Esperanto Brochure]

* [http://www.lojban.org/publications/brochures/brochure_french.txt|French Brochure]

* [http://www.lojban.org/publications/brochures/brochure_russian.html|Russian Brochure]



!!Other Non-English Links

* Note that [http://www.lojban.org/jbovlaste|The Lojban dictionary] has translations of many languages in it.

* Various learning materials are currently being translated or developed in [http://www.lojban.org/tiki/Mapa+Lo%C5%BCbanistanu|Polish] and [http://www.lojban.org/tiki/学習|Japanese].

* There is a [http://jolapache.free.fr/lojban/index.html|French website] with an exhaustive list of gismu and very nice charts of SELMAhO  from Jonathan.

* The gismu list was translated into [http://www.lojban.org/publications/wordlists/gismu_spanish.txt|Spanish]

* The gismu list was translated into ((gi'uste bau la daitc|German)).

*There is a partial ((Hebrew gismu List))

*There are [https://skami.iocikun.jp/lojban/valsi_tables.html|gismu and cmavo lists in many languages].

*For historical interest, here are some ((Old lojban.org Page Translations))

* See also the ((ongoing projects|ongoing projects list)) on the Wiki for some LLG-independent translation projects people are working on.
