This page is for errata in ((The Complete Lojban Language)), that is for mistakes such as typos, or self-contradictions, or contradictions with other baselined language definition material. This is __not__ a page to put desiderata (suggestions for improvement); such suggestions should go to ((Suggestions for CLL, second edition)).  This is also not a page to put errata resulting from the 4th Baseline Grammar proposal (i.e., the ((PEG)) grammar); PEG grammar errata should go to ((CLL PEG Errata)).



An online version of the CLL incorporating the changes on this page [http://lojban.github.com/cll/|is available].



See also [What+is+Lojban%3F+errata&bl=y|What is Lojban? errata] (for the published version), Level 0 Booklet Errata [tiki-editpage.php?page=Level+0+Booklet+Errata&lang=|?] (for the pre-publication reviews; now finished), and [Lessons+Errata&bl=y|Lessons Errata] (for the beginners' course).



The "''INCLUDED IN DAG-CLL''" tag means that http://lojban.github.com/cll/ includes this fix, which also means it'll probably be in the next CLL version.

This page is for errata in ((The Complete Lojban Language)), that is for mistakes such as typos, or self-contradictions, or contradictions with other baselined language definition material. This is __not__ a page to put desiderata (suggestions for improvement); such suggestions should go to ((Suggestions for CLL, second edition)).  This is also not a page to put errata resulting from the 4th Baseline Grammar proposal (i.e., the ((PEG)) grammar); PEG grammar errata should go to ((CLL PEG Errata)).

This page is for errata in ((The Complete Lojban Language)), that is for mistakes such as typos, or self-contradictions, or contradictions with other baselined language definition material. This is __not__ a page to put desiderata (suggestions for improvement); such suggestions should go to ((Suggestions for CLL, second edition)).  This is also not a page to put errata resulting from the 4th Baseline Grammar proposal (i.e., the ((PEG)) grammar); PEG grammar errata should go to ((CLL PEG Errata)).
