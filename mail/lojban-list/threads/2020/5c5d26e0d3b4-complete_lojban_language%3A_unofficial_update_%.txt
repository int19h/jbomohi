geklojban-1.2.3 is an unofficial version of CLL (The Complete Lojban 
Language <https://mw.lojban.org/papri/The_Complete_Lojban_Language>) book.

geklojban-1.2.3 is not necessarily approved by the LLG (Logical Language 
Group <https://mw.lojban.org/papri/Logical_Language_Group>) and therefore 
is not recommended for adoption.

The only reason for its existence is to test new features and send it for 
approval to the LLG.
How to use

   - 
   
   read the so called "difference" PDF document 
   <http://vrici.lojban.org/~gleki/build/cll_diffs/cll_difference_prefixed.pdf> that 
   compares geklojban-1.2.3 to CLL published in 2016 (2016-08-27 release). The 
   document has insertions marked with green and "ins`" prefix and deletions 
   marked with red and "del`" prefix. Prefixes are added so that you can use 
   Cmd+F or Ctrl+F to quickly find the differences in the PDF document. There 
   is an alternative difference version without prefixes 
   <http://vrici.lojban.org/~gleki/build/cll_diffs/cll_difference.pdf> (but 
   then you'll have to manually scroll the document to find the differences).
   - 
   
   or read the difference document in HTML format instead:
   - 
      
      with prefixes 
      <http://vrici.lojban.org/~gleki/build/cll_diffs/diff_new_xhtml_no_chunks/difference_prefixed.html>
      ,
      - 
      
      without prefixes 
      <http://vrici.lojban.org/~gleki/build/cll_diffs/diff_new_xhtml_no_chunks/difference_prefixed.html>
      .
      - 
   
   or read the final document that is to be used for printing and 
   publication. Notice that the title page has the document explicitly marked 
   as "geklojban-1.2.3" and has the name of the organization published it 
   different from LLG; this is done to emphasize that it's not an LLG 
   publication:
   - 
      
      PDF format <http://vrici.lojban.org/~gleki/build/cll.pdf>.
      - 
      
      EPUB format <http://vrici.lojban.org/~gleki/build/cll.epub>.
      - 
      
      HTML format, one page is one section of the book 
      <http://vrici.lojban.org/~gleki/build/xhtml_section_chunks/>.
      - 
      
      HTML format - the whole book in one very long page 
      <http://vrici.lojban.org/~gleki/build/>.
      
Short list of changes

   - 
   
   Dotside <https://mw.lojban.org/papri/Dotside> implemented
   - 
   
   "cmene" and "cmevla" concepts are now separated
   - 
   
   sumti tcita is renamed to sumtcita
   - 
   
   mi kucli le jei broda is now mi kucli tu'a le jei broda
   - 
   
   Dictionary with examples is now technically possible: the glossary may 
   have examples below definitions of words (and does so for the word coi as 
   a showcase)
   - 
   
   immense amount of mistypes and minor errors fixed
