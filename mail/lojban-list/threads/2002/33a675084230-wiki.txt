It currently uses phpwiki and mysql. phpwiki requires php4, and, I
believe, Apache. You could get it running on basically any free Unix,
maybe even some toy operating systems.

The zip file, however, contains 1 file per Wiki page, with the raw wiki
text of the page in the file, and the file name being the name of the
wiki page. It wouldn't be very difficult to load it into any number of
other Wikis. A few minutes of Perl could presumably convert from phpwiki's
wiki markup language to whatever new software you care to use.

There are any number of different Wiki software packages available for
every conceivable platform, including Emacs.
