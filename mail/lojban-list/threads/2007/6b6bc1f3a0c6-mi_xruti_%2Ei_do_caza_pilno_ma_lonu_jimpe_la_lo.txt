On Mon, Apr 02, 2007 at 03:38:48PM -0400, Rob Speer wrote:
> 
> So my question to the community is: how do you check your Lojban and
> look up words now? Is jbofihe still the command line tool of choice?

For word lookup, I usually use kdict, which I have permanently pointed to lojban.org. When I don't have my laptop handy, I use a bash script that calls the commandline dict client. When looking up nonce lujvo, I give the commandline dict client the "-s rafsi" option for each of the rafsi. (I haven't figured out how to do that with kdict).

I don't do a lot of sentence checking nowadays, and when I do, it's mostly for BPFK work. Robin and Jorge's parser, camxes, can display tree structures, but does not gloss. It's available at http://www.digitalkingdom.org/~rlpowell/hobbies/lojban/grammar/ .

> Is there a shiny Web interface to all of this?

There is a web interface to dict at: http://www.lojban.org/cgi-bin/dict.pl
There is no web interface to camxes (yet).
Jbofihe can be used online at: http://www.lojban.org/jboski/
