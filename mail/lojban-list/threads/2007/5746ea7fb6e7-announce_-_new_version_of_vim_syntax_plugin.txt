I am proud to announce a new version (3.14) of my Lojban syntax
highlighting plugin for the Vim text editor. Release is dedicated
to the transcendent number Pi and to the Day of the Soviet Army.
Previous published version was 3.11.

What's new in version 3.12:

- Plugin is now compatible with vlatai, valfendi, BPFK and Jorge
  personal opinions by default. In particular, the word {iglu} is
  considered valid now. The old behavior is still available as an
  option.

- One subtle bug in fine diagnostic is fixed. Previously the plugin did
  the rough classification correctly (the word is fu'ivla), but the fine
  details under some circumstances was wrong (reason why it is fu'ivla).
  Fine diagnostic can be seen by pressing '\k' with cursor on the word.

- Color of unassigned cmavo changed from red to blue.

- "Super-fancy" mode (fancy level = 2) is abolished.

- Better documentation (although separate documentation still doesn't
  exist, see comments at the top of plugin file instead).

What's new in version 3.13:

- Highlighting for non-fancy mode is generated now, not coded manually
  (this change is not user-visible).

What's new in version 3.14:

- Fixed some bugs introduced in version 3.13.

Plugin is downloadable from http://45.free.net/~slobin/vim/lojban.zip
