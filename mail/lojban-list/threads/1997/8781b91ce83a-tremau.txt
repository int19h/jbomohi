Chris:
>Could {nu} be defined as {ka fau makau}?

I don't think so.

I'm not too sure how {fau} is supposed to work. If we
assume that {mi klama le zarci fau ko'a} means that
{ko'a nu mi klama le zarci}, then {le nu mi klama
le zarci} would be equivalent to {le jaifau klama be le zarci
bei fai mi}. What you have would be a raised version
of that, and you couldn't use it in a place where you
would use a {le nu ...}.
