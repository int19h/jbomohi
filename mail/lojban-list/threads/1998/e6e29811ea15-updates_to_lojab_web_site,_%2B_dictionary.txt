There's a complete searchable Lojban-to-English dictionary now
available in the 'translation' section of my web site. It allows both
exact and substring searches. The dictionary file was compiled from
the ftp lists of gismu, cmavo, lujvo, etc. in the wordlists
directory. The compiled file was put into tex format and is also
available. The search program then searches the dictionary and gives
either an exact match or all listings for a substring. This dictionary
is searchable by Lojban only.

The web site was also spell-checked, and the volunteer section
substantially increased.

Any suggestions would be appreciated.
