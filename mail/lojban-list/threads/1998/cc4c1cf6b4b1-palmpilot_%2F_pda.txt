Does anyone on the list use a PalmPilot or other PDA?

I've recently converted the cmavo, gismu, rafsi and jvoste lists into Doc
format (a portable document format commonly used on the PalmPilot). The
files take up a total of about 300K (which fits easily into a PalmPilot Pro)
and can upload the converted Doc files onto a web site if other people would
like them.

I've found it extremely useful to have the Pilot available with these lists.
When going through the Reference Grammer or translating texts it's so easy
to be able to search the gismu and cmavo lists to aid in the translation. It
certainly saves having to be at a PC to look things up! Useful until the
dictionary gets published anyway.

I've also converted some of the tutorial files for 'light reading'.

Anyhow, just thought I'd pass the tip on. If anyone wants the databases just
let me know (although it's trivial to convert from the files available on
the ftp site to the Doc format using the programs available - I didn't have
to do much!).

One day I hope to be able to post such emails in lojban :)

Chris.

I've uploaded the Doc files to:

http://members.xoom.com/jwbooth/lojban/pp.zip

The zip file contains the gismu, rafsi, cmavu and jvoste lists available
from the lojban web site converted into AportisDoc databases. You should be
able to load these into your palmpilot and view them with Doc. If you have
any problems let me know.

They are just straight conversions form the html (except for the rafsi which
came from the ftp site) using the MakeDocW program so the format is a little
funny. When I get some time I may reform the files so they are a bit better
to view using Doc. I'll let you know if I do this. They are also straight
copies downloaded from my PP as I misplaced the originals on my hard drive
so hopefully the work with Doc alright :)

I've found them to be very useful as you can use all the searching features
of Doc to find gismu, english translations, etc. Now what I'd like is
PalmPilot versions of the lujvomaker, logflash, etc. Hmmm, maybe I should
put my developer cap on oneday :)

AportisDoc can be obtained from: http://www.aportis.com/

Hope this was useful.
