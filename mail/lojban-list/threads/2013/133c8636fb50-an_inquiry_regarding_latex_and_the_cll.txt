You probably know that there has been an effort to create a new CLL:

Robin:
>> Is there a goal statement for CLL1.1 which I can evaluate my (our)

> *Exactly* that.  Exactly what you said, without alteration.  The
> only clarification I'd make is importance: PDF > HTML > everything
> else.  Oh, and that the PDF needs to be something we can send to a

Would there be more people capable and willing to help out if Robin 
converted what is currently there to *LaTeX* (from docbook), so that you

this forward, so please speak up.

Who on this list can use LaTeX well enough and would be willing to help 
with the CLL?
