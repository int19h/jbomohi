Some ask how to use camxes (lojban parser) offline on Windows.

1. Install the latest version of Java from java.com
2. Download the archive attached to this message.
3. Unzip it.
4. Run "lojban_peg_parser.bat"
5. Enter a lojbanic sentence. Press "Enter". You can see the parsing of the 
text.
