No. {ijo} is "if and only if"; {ijonai} is "exclusive or". An arbitrarily long 
string of propositions connected by these is false if an odd number of them 
are false, or if an even number are false, depending on the number of {nai}. 
Think of those switches such that if you flip one, it turns the light off if 
it's on, or vice versa, and there are several in a room, all controlling the 
same light.
