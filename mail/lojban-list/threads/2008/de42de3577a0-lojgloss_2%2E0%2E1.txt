Lojgloss 2.0.1 has been released. I guess there are three features I
want to mention here. Mono, and thus Linux and OS X, is now supported
for the command line tool, but not the GUI (see below). Parse errors
are now displayed in an intelligent, nice format in the GUI. And there
are now tabs so you can easily have multiples instances of the parser
up in the same window.

I haven't gotten any feedback on the 2.0.0 release. Is anyone put off
by the requirement of the .NET 3.5 framework? If that's a big problem,
I may plan to work on a server-based version earlier than I would
otherwise, so please let me know.

I'd appreciate feedback on the error display feature. I'm not sure how
to go about displaying errors on the commandline. Reducing lojban
parse errors to a single message may be impossible to do in any useful
way, and displaying an error tree the same way the GUI

I looked into Mono's support of the WebBrowser control that I use in
Lojgloss 2.0, and it looks like they're still in the process of
implementing the parts that I use, so it could be some months before
non-Windows support of the GUI. On the other hand, I've confirmed that
the command-line client *does* work under Mono (with a couple changes)
and so 2.0.1 will support it.
