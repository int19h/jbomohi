Hi, I've just made a lot of my source available to the world,
including the source of Lojgloss. (This was precipitated by my getting
everything converted from svn into bzr.) It's using the Bazaar source
control system, which you can get at bazaar-vcs.org if you don't have
it. Here are the projects you need to branch for lojgloss:

bzr branch http://pdf23ds.net/bzr/Common/trunk
bzr branch http://pdf23ds.net/bzr/lib/xtc/local
bzr branch http://pdf23ds.net/bzr/PegParser/RatsInteg
bzr branch http://pdf23ds.net/bzr/Lojgloss/RatsInteg

They all expect to be in the same directory, and at the moment,
probably aren't close to a working state. You'll want to get in touch
with me if you actually want to do anything with the source.
