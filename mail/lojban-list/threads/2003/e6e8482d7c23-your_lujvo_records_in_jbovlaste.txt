To be more clear, if a place numbering field has more than n
<lerfu-string><number> pairs, where n is the number of components of the
lujvo, the first one indicates the actual lujvo place being discussed.

Just making that specific because I realized that otherwise lujvo that
start with x could be ambiguous.  In that case, the user should put more
than one letter after the lujvo term, just to be extra clear:

x1=xi3=xa2
