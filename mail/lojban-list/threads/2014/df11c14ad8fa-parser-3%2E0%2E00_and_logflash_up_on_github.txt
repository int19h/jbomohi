get LogFlash running, mostly as a historical curiosity. I did, though I had 
to comment out some of the memory management!*

compile and run, I figured I should put it up in our Github organization 
for posterity or the enjoyment of others or something. And once I had done 
that, I figured I might as well put up the old parser as well (which I had 
previously fiddled with and at one point had running as an IRC bot). The 
repositories are:
