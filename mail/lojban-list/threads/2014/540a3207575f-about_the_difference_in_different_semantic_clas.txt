Once there was a question what organisms belong to {curnu}.
The answer is that even snaked might be called "worms". If you don't like
it invent a new classification.

A more convincing example are words for taste:
We can classify substances into: acids, alkali, sugars, salts etc.
And we can classify them into: sweet, sour, umami, salty ...

They are completely different and almost never intersect.
Almost.
Because "salty" coincides with "alkali" as alkali can be made the prototype
of salty taste. Thus we need the same word for both classifications.
