Is the downloadable HTML version of the Reference Grammar found at 
http://www.lojban.org/tiki/The+Lojban+Reference+Grammar
the most recent version?

I prefer this version because each chapter is on one page,
which allows me to use [Ctrl]+F to find something I want to review.
However there are a few things that I want to change:

- redundant table of contents (TOC) at the top of each chapter
-- I want to use one tab in my browser for the chapter TOC
and have links open chapters in new tabs.
I have already made a separate TOC page, and the next step is to
convert the chapter TOC at the top of each page into a subsection TOC.

- unhelpful chapter titles for tab browsing 
(all you see is 'Lojban Reference Grammar..." on each tab)
-- I have reduced the titles to chapter numbers for now, 
but I also want to add very short descriptions (english or lojban 
suggestions are welcome).

- [div] tag structure for the TOC doesn't work well with Internet Explorer
-- I like to make sure things work with at least IE and Firefox.
(Done)

- no margin... endlessly stretching text is a crime against my computer 
screen (.u'i)
-- I like a central column with some space on either side.
(Done)

- [pre] tag is used with a monospaced font for tables, yet nothing is 
aligned for some reason
-- I could add spaces to align everything, 
or I could use the [table] tag, which I think will make things easier to 
read.
(compare the first table in chapter 13 of the attached zip file)

- opening quotes are double ``accent" marks
-- Is there some reason for this? 

- the same CSS at the top of every chapter (nitpicking... I know)
-- we can put CSS in its own file ;-]
(Done)

Attached is what I accomplished last night.
I'm going to wait for some feedback before converting the rest.
