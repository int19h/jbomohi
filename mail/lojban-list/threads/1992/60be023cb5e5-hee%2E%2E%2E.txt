Had to tell you this:

Remember I told you I was puttering with a MUD (not the one I'm still
waiting for it to return, where I'm a wizard, I'm talking about the
star-trek based one), where I was developing code so that people who spoke
different languages couldn't understand each other?  I generate gibberish
that looks like the language in question using the "names" program off the
PLS.  So I fed it a couple pages of Klingon and got Klingon gibberish,
someone managed to find a Romulan lexicon and got Romulan gibberish, I
threw in /usr/dict/words to get English gibberish.  I may one day make
Esperanto gibberish, hell, even Sign Language gibberish might be fun.  But
today I set up the Vulcan gibberish.  A long time ago on the
klingon-language list, when it still worked, someone posted a few Vulcan
lines from one of the movies.  It was really only ten lines, not enough to
work with.  But I thought it looked like another language that I could get
more of, so I used that.  Therefore, Vulcans on that MUD will actually wind
up speaking: gibberish Volap"uk.  I love it.
