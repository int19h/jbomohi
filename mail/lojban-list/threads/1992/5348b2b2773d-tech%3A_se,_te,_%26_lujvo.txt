jerna x1 earns x2 for work x3

_le se jerna_ can mean anything that is earnt.
Suppose one wanted a lujvo specifically meaning "wages":
could _seljerna_ be such a lujvo? (I.e. does it have to
be *synonymous* with _se jerna_?)

If _seljerna_ needn't be synonymous with _se jerna_, then,
I wonder, is there a way of forming a lujvo that yields
the x1 place of the source gismu, but isn't synonymous
with the source gismu?
Put another way:
 if     le se jerna =/= le seljerna
 then   le jerna =/= _____________ ???????

If _le se jerna_ = _le seljerna_, then why is Colin always using
_seljerna_-type lujvo?
