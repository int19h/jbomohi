Although I adore GoldenDict as
* free open-source
* full of features
* cross-platform
dictionary software

I realised several disadvantages of it
Firstly, it has to be INSTALLED
Secondly, it has to be installed separately for each operating system having 
another distibutive for each of them
Then you don't have an opportunity to perform full-text search within notes 
on valsi which is sometimes needed.
After all, many devices lie smartphones are not covered by this app at all !

So let me introduce fricukt alpha version based on TiddlyWiki and Goldendict 
dsl dictionaries.
Here <https://sites.google.com/site/slovlacukt/file-cabinet> is where you 
can get the latest build (fricult***.htm file).

This is how it is supposed to work.
It's just a webpage that should be understood by most devices (as HTML is 
covering more and more devices)
It performs full text search.
Currently only one dictionary （simplified gismu）is included.
But it's inside the file itself.

So you just download  and run it.
Type any gismu or translation into the  "sisku" field and you are done.

As the underlying code is simple everyone is free to improve fricukt.
I was able to run it even from my very old phone.

What do you think of fricukt (bearing in mind that it's alpha version) ?
