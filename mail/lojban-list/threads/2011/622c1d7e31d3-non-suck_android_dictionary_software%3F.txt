OK, let's determine whether it's ForaDict's fault or dsl's.
1. Create a file named 1.dsl using any simple text editor and  paste there 
the following text:

#INDEX_LANGUAGE "English"
#CONTENTS_LANGUAGE "French"

nest
       zdani


2. Create a file named 2.dsl using any simple text editor and  paste there 
the following text:


#NAME "Test2 (Eng-Jbo)"
#INDEX_LANGUAGE "English"
#CONTENTS_LANGUAGE "Lojban"

love
       prami
