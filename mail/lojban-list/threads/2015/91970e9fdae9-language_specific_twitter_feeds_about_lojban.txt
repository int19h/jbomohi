Hello,

Currently the twitter feed on the LMW front page is just a regular 
twitter search, and thus contains whatever is newest, which often is 
languages which the visitor might not know.

To solve this I wrote a small utility called bano[0], which uses the 
Twitter Search API's language search functionality to generate language 
specific feeds, to be run at some set interval as eg, a cronjob

Of cours, there isn't activity on twitter for all languages available on 
the LMW, so on the pages that there isn't activity for it might be best 
to either fall back to English, or to the current feed with all 
languages.

[0]: https://github.com/kyrias/bano
