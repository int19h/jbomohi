*CLL 1.0 Chapter 6:
*
15.3)  li .abu bopi'i xy. bote'a re su'i by. bopi'i xy. su'i cy.
        the-number a times x to-power 2 plus b times x plus c
        ax^2   + bx + c

It's the first time ever I see this bo+VUhU pattern, and it seems this 
example sentence from the CLL is not grammatical under any of the 
following parsers: YACC, Jbofihe, Visual Camxes, Camxes JS.

Any idea where this grammar comes from, and whether the aforementioned 
parsers are wrong for not supporting it?

I don't see any reference to this in the CLL errata.

I'm convinced this is a CLL error. It looks like the intent is to get 
right-associativity, so that the ^2 affects "x", and so "x^2" is in turn 
multiplied by "a". In the second term, the "bo" is used particularly for 
tight binding, to prevent the default equal left-association of all 
VUhU. These BO+VUhU should all be VUhU+BO.
