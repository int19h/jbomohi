How do I get rid of spams?

(Possible answer) The mailing list for lojban is courtesy of columbia
university which does not have a very good spam filter. You can filter
these out using  (for example) Eudora's filtering mechanism. The filter to
use is:
Filter out email containing the text string "(Unverified)" on the
"X-Sender" line; spammers generate this string as part of their evil
machinations to avoid hate email. Instead of filtering the spams into a Mac
Folder or PC directory, send them directly to the Trash (Mac) or select the
"don't save" option (PC).

Is there a Mac Version of Lojflash?

(Possible answer) Sure. MacLojflash 1.7. It can be obtained directly from
the author, Richard Kennaway, at jrk@sys.uea.ac.uk (Chris, you probably
want to check with Richard to make sure it is o.k. with him to include this
in the FAQ file.)
