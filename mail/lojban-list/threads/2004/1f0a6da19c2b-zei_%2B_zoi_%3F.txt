Both jbofie and the official parser accept

    le zoi ibu cgi-bin ibu zei samselpla

which is only possible if the zoi clause is treated as part of the zei
clause, which means treating the zoi clause as a single word.

I can find no justification for this behaviour in grammar.300; it looks
wrong to me.

Any opinions?

That's right. {i bu} is not a word, so you have:

{le zoi i bu cgi-bin i bu zei samselpla}, which means the
same as {le bu zei samselpla pe zoi i bu cgi-bin i}.
The preparser will deal first with zoi, then with zei 
and only then with bu, if they had not been swallowed.

Wait, *no*, that's wrong.

    a. If the Lojban word "zoi" (selma'o ZOI) is identified, take the
    following Lojban word (which should be end delimited with a pause
    for separation from the following non-Lojban text) as an opening
    delimiter.

To interpret it as you're suggesting requires that "i" be eaten without
a following pause delimiter.  Whether that matters in this case I'm not
sure, but it certainly violates grammar.300.
