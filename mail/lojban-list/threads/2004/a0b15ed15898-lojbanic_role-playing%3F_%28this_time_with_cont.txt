I've been thinking about running an RPG of some kind entirely in Lojban.

I'm assuming here that no-one *else* would want to run one; if you do,
please speak up!

For a long time I was thinking about doing my own world, and using FUDGE
to roll my own gaming system and so on.

I've decided that's dumb: it's going to be hard enough to do this
without me also trying to be creative.

So now I'm thinking a straight D&D game, with a standard D&D module.  No
creativity for me at all.  :-)  Something creative on the second
go-round, maybe.

I'm thinking the media will be e-mail, IRC, TeamSpeak, or a combination
of them all.  All sessions would be recorded for posterity, of course.

Who's interested?
