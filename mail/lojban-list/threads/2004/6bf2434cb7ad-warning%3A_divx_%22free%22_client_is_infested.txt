The DivX "free" (as in beer) client for Windows that Robin's
page points to is infested with Gator as well as possibly other
adware/spyware programs.  If you have loaded it, get Spyware S & D
http://security.kolla.de and grab the latest update.  You will need
to scan for problems and fix them, and then you will have to reboot
and let Spybot run at boot time.  It will scan again, and you need
to fix the remaining problems.

After that, the client will still work, but it is no longer licensed;
you should remove it.
