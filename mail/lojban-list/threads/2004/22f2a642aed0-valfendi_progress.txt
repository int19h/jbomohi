valfendi is checking rafsi for validity, but it's missing some. If the rafsi, 
or the result of appending a vowel to it, is a valid fu'ivla that ends in one 
vowel, it appears to accept or reject it correctly, but it erroneously 
accepts {rafytestudine} and {teryklambati'a}. It also outputs the wrong error 
in some cases; e.g. for {teryklambati} it says "unnecessary y-hyphen".

When it appears to be working right, I'll release version 0.2.0pre1, which 
won't have the algorithm for checking brivla validity written in 
valfendi.txt, just in the code. This'll give RLP and anyone else a chance to 
try it out or compare it with the PEG grammar.
