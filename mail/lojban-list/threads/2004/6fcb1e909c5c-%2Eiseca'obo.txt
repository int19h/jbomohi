--- Robin Lee Powell <rlpowell@digitalkingdom.org> wrote:
> Hint: it doesn't mean anything; ca'o has no places, and thus can't take
> SE.

Any sumti tcita must relate two things, the sumti it tags and the
event it modifies, so SE makes as much sense on any tag as it does
on BAI. I have proposed a simplified grammar of tags here:
<http://www.lojban.org/tiki/tiki-index.php?page=Internal+grammar+of+tags>
which allows SE on any tag.

<bridi1> ica'obo <bridi2> means that the event described by <bridi1>
is ongoing when the event described by <bridi2> happens.
<bridi1> iseca'obo <bridi2> would mean that the event described by 
<bridi2> is ongoing when the event described by <bridi1> happens.
There is nothing strange about that. 

(Possibly the meanings are the other way around. This is not
a well defined area of the language. Not all tags behave in the same
direction when used as bridi connectives.)

I wrote something about tags as connectives here:
<http://www.lojban.org/tiki/tiki-index.php?page=tags+as+connectives>
