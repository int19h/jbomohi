> But I was asking about the difference between {le} and {lo} (which
> seems to parallel the difference between {lei} and {loi}).

To decide whether {le cukta cu blanu} is true, first work out which
entity the speaker means {le cukta} to refer to, and then check whether
it is blanu.
To decide whether {lo cukta cu blanu} is true, inspect the intersection
of the set of all cukta and the set of all blanu. If the intersection
is non-empty, then the proposition is true. If it's empty, it's false.

{lo} works like an existentially quantified variable.
{le} works like a constant.
