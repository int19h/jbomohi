la xorxes cu cusku di'e:
>xu la'edi'u fasnu ri'i na'ebomi ji'a

.i go'i .iku'i mi jai rirci

>i xu da djica le nu te lisri de lo tordu
.i go'i ni'o


zukuzuku pa remna le terdi midju cu kucli .i co'a litru .aidai .i ze'uve'u
cadzu pa'omo'i loi ricfoi jo'u loi cmana jo'u loi xamsi .i piso'u loika
jmive cu go'i purci .i .uodai cpana be lo cmana be'o sanli gi'e viska le
vi'a sugda ke ganra plita poi midju le terdi .i vo da le plita cu klaji le
midju .i da le satci midju cu sirji le berti .e le stuna .e le stici .e le
snanu .i le sisku cu ni'amo'i cpare le cmana .i co'a dzukla le midju
ni'o
.uodai le tatpi nalcitno co'a zvati le midju .i vode poi rokci bargu cu
vorme le vo klaji le satci midju be le terdi .i le vorme cu se nenri pa
banli ke torni brife .i loi pulce cu vi'u comymu'u .i le litru cu ne'imo'i
juxre cadzu
.i le brife cu cmoni
.i lu xu do cevni li'u preti le brife le litru
.i le brife cu torni cmoni
.i mi ze'u sisku sei cusku
.i loi pulce ca'o dansu
.i le remna cu jorne dzukla le torni gi'ebabo galtu se bevri gi'ebabo janli
le snuna vorme
.i le ra rectu cu ze'u se citka le pulce
.i le ra greku cu ze'u se blabygau le solri
.i le torni brife ca'o cmoni
