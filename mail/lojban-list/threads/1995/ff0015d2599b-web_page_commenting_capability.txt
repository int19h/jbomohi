I have tested an add-on to the Web server - HyperNews - which makes
it possible to add user comments to selected documents on the Web
(WWW only, but the documents need NOT be situated at this very server).
Any FORMS capable client program can be used to add comments to
a comment tree (comments on the base document, comments on the 1st
level comments, ...) - I have tested the system with Lynx, Mosaic and
Netscape.

I already set up a guest book for the server but the main use might be
providing a number of forums, public or private, around selected topics.
We could also get user feedback for selected documents on the server.

I just got the thing running so I haven't had much time to think about
the pros and cons. Any ideas?
