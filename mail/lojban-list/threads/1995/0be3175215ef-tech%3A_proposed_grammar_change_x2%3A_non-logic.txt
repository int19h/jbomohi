CHANGE X2

PRESENT LANGUAGE:

Non-logical connectives can be used in forethought to connect bridi-tails,
but not in afterthought.

PROPOSED CHANGE:

Add "GI joik" as a gihek.

RATIONALE:

Allow the flexibility of afterthought to an already existing possibility
in forethought. Rationalize the connective system.

NOTE: This change is an extension. It does not affect any existing
grammatical text.
