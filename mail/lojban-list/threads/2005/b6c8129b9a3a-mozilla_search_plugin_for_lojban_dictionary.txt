I created a simple search plugin for Mozilla and Firefox browsers that 
works with the built-in search bar, alongside Google, DMOZ, and other 
search engine choices. I've attached the plugin files to this message.

The png file contains a small Lojban icon that shows up on the search 
field.
The src file contains an HTML-ish fragment used by the Mozilla search 
plugin to query the Lojban dictionary.

To use the search plugin, drop the png file and src file into the search 
plugin directory for Mozilla and/or Firefox. (Look at the source first 
-- don't automatically trust any software from any group posting!)
On Windows systems, these directories are usually:

C:\Program Files\mozilla.org\Mozilla\searchplugins
C:\Program Files\Mozilla Firefox\searchplugins

The attached JPEG image shows the plugin operating within Firefox. (You 
don't need to place the JPEG anywhere, it's just for illustration.)
Then close all Mozilla or Firefox windows.
In Firefox, you should see the Lojban entry in your search engine list 
(click the Google icon to see the list).
In Mozilla, you can press F9 to see the search sidebar.

I've found the plugin very useful in quickly looking up Lojban/English 
words from Firefox. It works using the "Any<->Any" option of the 
dictionary, so it matches on entries in other languages besides English. 
I submitted this to Mozilla about 2 weeks ago to include in their 
official search plugins list, but as of today it's still not listed.
