I'm in the process of moving the main lojban.org site to a Content
Management System (read: "something I and others can edit easily")
both to make my life easier and to make the site more responsive
(which, by my standards, it hasn't been).

The CMS in question is just Tiki, which is what's been running on
wiki.lojban.org For Some Time Now.

As part of this, I've made a new left-bar menu.  I've also cleaned
things up so that if you're not logged in, there should be very
little cruft on the page.

I am now open for comments on the current design.  Comments related
to the menu are *especially* welcome.

So http://lojban.org is not running Tiki yet? We're commenting just on
the design of wiki.lojban.org?

I still think it's much too cluttered to be used as a main page. That
"toolbar" thing at the top (with the 3d button and print and export to
pdf and such) is superfluous to the vast majority of visitors. The
left side containing all the toolbars should be in a font at least one
size smaller (like, small or x-small instead of medium). In the
default color scheme, the blue headers of the bars draw way too much
attention to them, when the attention should be first drawn to the
content in the center. The toolbar headers need to be much lower
contrast, or there should be a different background or border around
the main body to make it draw the eye.

Chris Capel
