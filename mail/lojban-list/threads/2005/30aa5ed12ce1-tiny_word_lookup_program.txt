I've writen a smallish program (in Python) for looking up Lojban words from
various word lists.  It can search for gismu, cmavo, rafsi, and lujvo.  I
plan to add support for looking up Lojban equivalents to english words at
some time.  The program is usable already though and as I don't know when I
will get around to this again I've decided to make a beta release.

Find a zip of the needed files here:
http://kitsu.petesdomain.com/files/lojban/Lojban-search.zip

I developed this with Python 2.3.4, but any 2.x Python should work.
http://www.python.org/

As an added bonus the program will also work on WindowsCE.  I have some files
for PythonCE hosted here:
http://kitsu.petesdomain.com/files/WinCE/

You'll need python and tkinter to run the program.

Anyway its nothing too fancy but it works.  Feel free to modify the program
to suit your needs.
