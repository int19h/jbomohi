Unzip the zip file.

For each file under home/www/twiki/data (these are the actual pages,
rather than the attached files):

    Find or create a Tiki page with a similar purpose.

    Post the text in that page, converting markup styles as
    necessary.

    Delete the file from your unzipped archive.

I can create conversion scripts to aid in that last bit.

For each file under home/www/twiki/pub (the attached files):

    Find or create a page on the Tiki for which the file makes sense
    as an attachment.

    Attach the file.

    Edit the page's text to insert a bit like
    {ATTACH(name=>filename.ext,inline=>1)}file description{ATTACH}

	This last bit creates a link to the file.

    Delete the file from your unzipped archive.

Repeat until no more files are left.  There are 120 in the archive.
