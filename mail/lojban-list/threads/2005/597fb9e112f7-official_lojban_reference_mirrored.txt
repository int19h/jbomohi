with Lojban Language Group's permission, i've mirrored the official 
lojban grammar here:

http://xahlee.org/lojban/hrefgram/index.html

There is no content change from the official version on lojban.org, 
except HTML/CSS styles. (i.e. i've moved the table of content to its 
own page, and have used utf8 encoding, changed quotes ``'' to curly 
ones “”, removed some css font specification, moved embeded css in each 
file to a outside file, and possibly in the future will add minor css 
tweaks such as coloring to make examples standing out, or breaking 
chapters into smaller units. (as i read it and learn more of its html 
structures/usage.)).

comment and suggestions welcome. If anyone likes (and with permission 
of LLG), i can sent a zipped version. The python script that made the 
change is also available.
