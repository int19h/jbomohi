i've broken the official lojban ref grammar
http://lojban.org/publications/level0.html

into a version that's a section per html page:
http://xahlee.org/lojban/hrefgram2/index.html
(for easier leisure periodic reading)

Here's some notes about the change:
• Chapter 1 is still the whole chapter in one html page.
• Chapter 4's illustration has been deleted.
• Here's some html changes that are made (refer to earlier post also if 
i missed something here):
  * the XML doc type is changed to HTML.
  * In general i tried to make the XML/HTML more valid.
  * I've replaced quotes ``'' by pretty quotes “”, and -- by —, etc. 
(see earlier post)
• The content has not been changed.

If you like to mirror this per-section version, with all due 
copyright/licensing issues from the Lojban Language Group Incorporated 
( http://lojban.org/llg/genlic.html ), you can download the html per 
section version i've made at:

  http://xahlee.org/lojban/hrefgram2.zip

This archive will be removed in a week or so.

Although this newer doc's underlying XML/HTML code has gone thru 
somewhat extensive change, but still the final result is not a valid 
XML/HTML doc. I think the only one problem left is that some paragraphs 
don't have <p> tags. Such paragraphs you can see that run over to the 
right edge of the window. e.g.
first paragraph at:
http://xahlee.org/lojban/hrefgram2/c6-s04.html

i haven't looked if there is a safe systematic way to search & add the 
tag.

If you intend to mirror the doc, or if lojban group like to use it etc, 
note that the header & footer pertinent to my own site can be easily 
removed by a find & replace text editor or tool. Also, the style sheet 
can also be easily edited.

A new html problem with the new version is that many links to examples 
are broken, because of the section separation. I haven't thought of a 
safe and systematic way to fix this.

The version on my site
http://xahlee.org/lojban/hrefgram2/index.html
will gradually change as i read each section in more detail.
I intend to modify it to a somewhat leaner version so that the output 
is more suitable for a general reader, or perhaps condense it by remove 
any background discussion or extra linguistic info. (i plan to do this 
very slowly, perhaps up to a year.)

In this process, i will be fixing all the missing <p></p> tags and 
broken links... but probably not before i edit the content as well. So, 
if anyone like to rip the fruit of this per-section version, grab the 
zip file now and go from there.
