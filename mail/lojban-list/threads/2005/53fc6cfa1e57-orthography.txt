Here's a fun orthography I made up. It's not very useful for
computers, but it would be great for watches or alarm clocks with the
7-LED characters. I also made a script version, which is fun to write
on paper and looks somewhat like Hindi script. It's pretty easy to
learn, because the consonants are grouped into voiced-unvoiced pairs.

http://www.calpoly.edu/~bwirick/orthography.jpg

pulenumi
mórsikeiku
roleilójbo
bateckíre

mi'e .uirik.

I certainly considered it, but {xy} is truly an unvoiced consonant, so
it should be in the same family as the other unvoiced consonants.
Since it is the only one without a voiced counterpart, {y'y} had
nowhere to go, and they're somewhat similar sounds, I stuck {y'y} in
that hole. I also considered putting {ry} there instead (doesn't a
voiced velar fricative technically count as {ry}?) but that was weird
all over, so I declined.
