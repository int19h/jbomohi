Hi all.

I've put together a set of flashcards for use with JDictP (a flashcard 
learning program) for the Palm Pilot. Instructions for use and the 
database are here: http://www.gulik.co.nz/jdictp-lojban.zip.

Unfortunately, JDictP is pretty damn hard to get installed and use. It 
is definitely not user friendly, and not particularly suited for using a 
thousand flashcards at a time (i.e. it randomly shuffles them...). 
However, it is free software and open-source. It runs on SuperWaba, 
meaning that it would run on PalmPilots, Windows CE devices, Windows, 
Linux and any other Java-capable environment. You do need to be pretty 
tech-savvy though, and SuperMemo is still much better.
