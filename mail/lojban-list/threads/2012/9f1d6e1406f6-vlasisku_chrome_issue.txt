Hey, I don't know if anybody else uses this feature of chrome but I use it
everywhere.

If you start typing a website into the address bar and google recognizes it
as something that has a search field, you can hit tab and start typing a
query.  e.g. I probably type out "en.wik{TAB}<something I want to learn
about>{ENTER}" about 20 times a day.

With that as the context; when I start typing in vlasisku.lojban.org I get
that same option, "Search Lojban dictionary", but then when I hit tab and
type my query like "julne", it takes me to "vrici:8000/vlasisku/julne".

Does anybody have any ideas about what might be happening here?

Neither of these have a search bar for them, however, so making a keyword
for them has to be done manually.

.camxes. -> "http://camxes.lojban.org/camxes/?text=%s"
jboski -> "http://www.lojban.org/jboski/index.php?jbocku=%s"

<DT><A HREF="http://camxes.lojban.org/camxes/?text=%s"
