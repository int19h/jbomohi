coi la'oi shanoxilt

It's the source code to genrei. It's written in Haskell and it is run as a
CGI script (za'a ju'o cu'i). You (or someone else) would need to download
the source code, install Haskell, install a web server application (e.g.
apache), install the source code (by running `cabal configure` and then
`cabal install` in the directory), and point the web server application at
the resulting exectuable.

If you know someone who administers a publicly facing web server, you might
ask them (off list; everyone on the list who can or is willing is swamped
AFAIK).
