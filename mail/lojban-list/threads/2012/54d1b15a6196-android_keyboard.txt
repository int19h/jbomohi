So, I've seen various posts come and go regarding Anki, Memrise, etc, but I 
haven't seen anything regarding the basic input mechanism.

Looking around, I've found a couple of things:
1) AnySoftKeyboard, which is nice and has an explicit make-a-dictionary 
manual <http://code.google.com/p/softkeyboard/wiki/HowToCreateLanguagePack>, 
though I know nothing of Java and have not been a fan of attempting to set 
up Eclipse.
2) MultiLing Keyboard<http://stunningapps.net/multiling_keyboard_for_android/com.klye.ime.latin>, 
which oddly lists Lojban in a language list on the download page, but not 
on the dictionary list when you get the actual application. (at least, as 
far as I could tell)

Before I devoted any more time to this, I was wondering if anyone had 
already put effort into it. In my mind, trying to add a dictionary based on the 
frequency list <http://www.lojban.org/tiki/Word+frequency+lists%3A+gismu> and 
the word lists on lojban.org would be straightforward. 

Alternatively, if someone knowledgeable in java could at least find a way 
to provide a blank dictionary, that would be probably be a great start for 
anyone in any context.

Any ideas?
