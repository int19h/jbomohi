I've just finished the initial version of "lojbo jufsisku" (Lojban
sentence search), which is a bilingual (Lojban-English) translation
search environment in order to facilitate dictionary and translation
look-up for anyone who writes in Lojban:

http://lojban.lilyx.net/jufsisku/

I've added sentences from Tatoeba, some part of CLL (Chapter 1 to 4),
lu la teris. po'u le tirxu li'u, and jbovlaste.
I'm planning to add more sentences myself, but it'd be great if
jbopre's in the community help make it a better tool by adding more
(hopefully high-quality) sentences.

Quality and quantity of sentences are critical to its usefulness.

Any feedback is appreciated!

Thanks,
Masato

Yeah I did get at the time that what I was saying may not sound that
productive, especially my opt-out at the end :-)

Other reasons not to use that *particular* map mashup service (other
free ones exist that may be fine):

* The data isn't ours and can't be exported.  Not good if we wanted to
list it, search it, export to another mapping service, pipe it into
mobile apps, or simply make a back-up.  Lock-in == lose.
* It doesn't appear the data can be be updated once submitted - it's a
one-shot process.  Using the tiki for authentication ties a user to a
given account and allows re-authentication without a separate
extraneous database.
* There are no anti-spam measures, a map could end up littered with
"free pr0nz here" with a tag on your house, for example.  On that
example map, check out the alien in Russia, he loves burgers.
* We can't customise the fields being captured - some basic contact
details at the very least might be useful.  Using the tiki's
authentication could allow for an automated link back to a user's
"About Me" page.

I see value in being a tool-loving nerd sometimes ;-)
