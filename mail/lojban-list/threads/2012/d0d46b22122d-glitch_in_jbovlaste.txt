Trying to search for mikri with valsi today in #lojban yielded some
interesting, albeit perhaps already known errors in jbovlaste.
It turns out that jbovlaste has some major issues in the way it
handles links and TeX and exponentials. In fact, jbovlaste thinks that
the -6 in [$10^{-6}$] is a link.
It seems like valsi doesn't quite have this problem, which means that
donri knows what ey's doing :) Searching for "1E-6" *does* return
{mikri} in valsi.

Now, I don't know if it's actually possible to *fix* JVS because ti'e
the original developer is no longer with us and no one knows how to
use ey's stuff.
At least, can we say that in JVS2 this will be fixed?
