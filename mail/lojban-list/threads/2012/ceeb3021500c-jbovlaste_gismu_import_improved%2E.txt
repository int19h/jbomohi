With the help of Ali, the jbovlaste gismu import script is now not a
horrible piece of shit.

I wanted to point this out in case there are translations floating
around that I don't know about, or that I failed to import, or
whatever.  It's way easier to give me a spreadsheet or something
than to use the UI for this many words.

Here's the format that the script expects, although if you have
something else we can work on it; I'm very very good at text
transformation.

All input should be UTF-8 encoded.

# All input files must match the following format.
# 1. All values must be seperated by Tabs
# 2. rafsi should not be included
# 3. The four columns should be in the following order:
# #  a) gismu
# #  b) glossword
# #  c) definition
# #  d) notes
# 4. The definition and the notes must already be jbovlaste-ified;
# this means that the definition must have LaTeX-style $x_1$ places
# in it, and the notes field must have cross-references like
# {bacru}.
#
# The import will fail if the above conditions are not met.
#

-Robin
