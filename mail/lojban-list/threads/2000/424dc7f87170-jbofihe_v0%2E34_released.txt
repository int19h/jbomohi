I have released version 0.34 of jbofihe (my software which parses Lojban
text for grammatical accuracy and provides rough translations of the
words into English).

>From the NEWS file :

New in version 0.34
===================

- Add support + translations for the cmavo that were missing from the original
  cmavo list
- Fix bugs in handling certain cmavo when followed by an indicator (e.g. mi se
  cai zdile)
- Fix bugs in cases when constructions involving lu, bu, lo'u...le'u, zo, zoi
  etc are nested.

See http://go.to/jbofihe/
