ni'o le brajatna catlu le vipsi *zi simlu zu*

Don't think that this will work for several reasons:

1) {zi} and {zu} stand for *distance* in time; you want to express time *intervals* So, e.g. putting {zi} at its proper place left of 
the selbri, it woun't have the desired meaning: le brajatna (pu)zi catlu le vipsi (... a short time ago) so {ze'i}/{ze'u} seems more 
appropriate.
   
2) {catlu} has only 2 places, so one would have to create a further one, maybe by using modals.
3) lastly, the (short) time interval has to be commented as seeming "age-long" -  not too easy! Will have to think it over.

Maybe like this (although a bit verbose):
.i le brajatna caze'i catlu le vipsi noi se simlu le li'i ze'uku di'u
