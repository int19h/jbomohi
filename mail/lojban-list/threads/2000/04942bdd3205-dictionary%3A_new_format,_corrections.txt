I haven't been on the list for a while, so forgive (and pity) me if
I've duplicated existing work.

I recently started using dict (www.dict.org) just to have a dictionary
on my computer.  It's quite nice.  With a single query it does lookups
on a set of databases local and remote, and it has a number of
different front ends including command line, GUI, and web.

I have Wordnet, The Jargon File, and the 1913 Webster's English
dictionary everyone seems to use.  I thought it would be fun to have
the Lojban dictionary in there too, so I reformatted it today.

I wrote one script to reformat the TeX source of the dictionary into a
human-readable text version suitable for the server, another to
generate the index the server needs, and a Makefile to coordinate
everything.

I've put the programs and their output all up at
http://www.aigeek.com/lojban/

It would be nice to give it to dict.org so they could redistribute it,
but I'll let LLG make that decision.  I'd understand if they wanted to
hold off until the final draft of the dictionary.  Distribution
generates interest though, and there's no information in here that's
not already available on the Lojban web site.


In the process of all the reformatting, I discovered some errors in
the TeX source.  I've included corrections below.  It's an amusing
selection of words.

The TeX source I'm using is dated Dec 20, 1993.  Is there a newer
version?
