I hit the same problem. I tried quite many tricks to
get it work since I usually have my desktop so
cluttered that shutdown restarts my world as a side
effect :). (I don't particularly like if my computer
has down moments more often than I do).

Well, in the end it wasn't so hard.

First, one has to get copy of LogFlash somewhere what
dosemu can read and write, be it ramdisk, file mapped
fs with fat, diskette or dos partition. But I guess
you had this since you're had an error. (Just to make
this explanation a little bit more complete:).

Second step is to get the files to train with. For
some unknown reason lf.exe is unable to create them
under emulation. So I just copied my files from Dos
and it works beautifully.

I guess some kind soul could put just generated files
( that is open LF.exe, name your session, say for
TEST, and immediately quit) on the net, so Linux
masses would be able to exercise vocabulary. 

I'd do it but I have at least 25 working windows open
:). Maybe when this crashes next time... But don't
hold your breath, has been up now over three weeks
since I last updated kernel.
