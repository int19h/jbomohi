I've got in running under Debian with DOSemu 0.98.8.0 and
FreeDOS kernel version 1.1.17. If you want, you can try
out a floppy image I created with freedos and logflash on
it to see if it works for you:

http://www.barsoom.net/lojban/logflash-freedos.img.gz

you should be able to use it by doing the following:

$gunzip logflash-freedos.img.gz #assuming your browser didn't do this already
$dd if=logflash-freedos.img of=/dev/fd0 #be sure there's a blank floppy there
$dos -A
