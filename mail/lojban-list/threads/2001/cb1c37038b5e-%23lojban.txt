EFnet or any other IRC server is not difficult to connect to. However, as
you have discovered, these servers require "identd" to be running on your
host system. For the mIRC client, if you are running windows, this is
enabled by setting it up in one of the pull down menus at the top of the
scree (read the documentation for mIRC). For Linux, install the identd
daemon software and run it. On Debian for example, it would be:
root:# apt-get install identd; /etc/init.d/identd start
I am sorry my memory does not allow me to be more specific for windows. I
used to use mIRC on it ages ago until I discovered Linux :)
