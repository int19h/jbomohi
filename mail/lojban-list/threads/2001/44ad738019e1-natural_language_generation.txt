by accident i found this page on a natural language generation system (kpml)	 
	    http://www.darmstadt.gmd.de/publish/komet/kpml-1-doc/kpml.html 
newer versions and a shorter description can be found at
http://www.fb10.uni-bremen.de/anglistik/langpro/kpml/kpml-description.htm

it is a freely available program written in ansi lisp, that can translate 
lisp expressions into a number of natural languages more or less well. the 
only catch about it seems that it requires a specific graphical user 
unterface (common lisp interface manager) of which only commercial version 
are available. a free inplementation called free-clim i could find almost no 
information about. but still, if lojban sentences can be turned into lisp 
expressions easily, kpml may be good enough to translate patents. perhaps 
somebody more knowledgeable con assess the utility of this suggestion.

this is what the input to kpml looks like, using a functional grammar it then
puts out something quite appropriate in the desired language. i may be wrong,
but the presented logical form to me seems close to a lojban syntax tree. i
am going to try to find out about the specs of these logical forms, if that
is of any relevance to our problem.

(EXAMPLE

    :NAME   3-D-TIME2
    :GENERATEDFORM   "1899 berief Ernst Ludwig ihn nach der
    : Kuenstlerkolonie." TARGETFORM   "1899 berief ihn (der Grossherzog)
    : Ernst Ludwig in die

Kuenstlerkolonie nach Darmstadt."

    :LOGICALFORM

(DA / DIRECTED-ACTION :TENSE PAST :LEX BERUFEN-3P-SG-PAST

    :SPATIAL-TEMPORAL-CIRCUMSTANCE-Q SPATIAL-TEMPORAL
    :CIRCUMSTANTIAL-THEME-Q CONTEXT :RELATIONS

    (TN / TEMPORAL-NONORDERING :RELATION-EXPLICITNESS-Q NONEXPLICIT

        :RANGE

        (T1 / YEAR :NAME EIGHTEEN-NINETYNINE))

    :ACTOR

    (P1 / PERSON :NAME ERNST-LUDWIG :IDENTIFIABILITY-Q IDENTIFIABLE

        :MULTIPLICITY-Q UNITARY :SINGULARITY-Q SINGULAR
        :CLASS-ASCRIPTION

        (OB1 / OBJECT :LEX GROSSHERZOG-SG-NOM))

    :ACTEE

    (ER / PERSON :MEMBER-SET-Q
        (SPEAKER ER)
        NOTINCLUDED :MULTIPLICITY-Q UNITARY :EMPTY-NUMBER-Q EMPTY

        :IDENTIFIABILITY-Q IDENTIFIABLE :GENDER-Q MALE)
    :
    :DESTINATION

    (TD / THREE-D-LOCATION :LEX KUENSTLERKOLONIE-SG-ACC

        :IDENTIFIABILITY-Q IDENTIFIABLE :MULTIPLICITY-Q UNITARY
        :SINGULARITY-Q NONSINGULAR :RELATIONS

        (DE / DESTINATION :DIRECTED-RELATION-Q DIRECTION :RANGE
            (OB2 / OBJECT :NAME DARMSTADT))))

    :SET-NAME   |prep-egs-1|

)
