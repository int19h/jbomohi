.i lo'e tarmi ku fa'u lo'e se tutci .i ve pante le palci nu tolylogji
pensi

vanbi le nu le dei ve pante cu se finti

.i .e'a do naltcidu dei poi pagbu .i zi le djedi be li so'o to detri
le nu mi cusku dei kei fa li pasosoze pi'e papa pi'e reno toi mi pu
zvati la'o zoi AmberMUSH zoi noi seltcidu selcmu se kelci lo'e za'umei
ku'o ca le nu da te preti fi lu .ei mi ca le nu xislu remei marce
litru cu dasni lei tolmle gluta gi'i seke lunbe xance li'u .i mi fadni
spuda fi lu ko dasni lei gluta li'u .i ji'a mi jmina cusku ku'i da poi
co'a cinri .i lu le nu makau se tutci cu vajmau le nu makau tarmi kei
roroiku .i le nu se vajni le tarmi noi zmadu cu se jalge le
cinlydusterbi'a .e lo'e xraselcmu ke samrxuebe jarco li'u .a lo seke
mintu smuni .i mi de'anai pensi le sidbo no'u le du'u le dei cmalu se
srera noi pamei cu rinka so'isai da poi nabmi le ma'a cecmu za'a .i mi
co'i tavla ze'u le mentu be li so'o .i ku'i le nomei cu se vajni ja'e
le nu mi sisti .i bazabo ba le nu cinri tavla fi le dei se casnu fe le
mamspe be mi kei mi co'a finti dei poi ve pante

lo'e tarmi se srera

.i pa le so'umoi co fadni se srera be loi remna bei ca ro se gasnu be
ry. cu me le se cmene be fi mi bei fe lu lo'e tarmi se srera li'u .i
le se srera cu sa'u nu krici le du'u le tarmi be le dacti cu vajni
ki'u le nei .i .ai mi darlu sepi'o le dei ve pante le du'u le go'i cu
za'umoi mupli le nu loi remna cu se jinzi le ka tolracli

.i caku do la'a ca'o pensi jinvi la'e lu .ie .i ku'i .ienai mu'a lo'e
se jadni purdi .e lo'e dinju finti saske .e lo'e larcu se cupra li'o
li'u .i li'a va'o ro le tcini le tarmi be le dacti ba'e simlu le ka
vajni ki'u vo'a .i la'e di'u jicmu le se srera .i ko pensi la'e di'e
.i ma se tutci lo'e se jadni purdi .i le nu pluka va'o le nu ganse .i
le nu melbi fi le ka viska je sumne jecu'i pencu ce'u .i ro ma'a noi
seke marji xadni cu tcaci fendi le tolmucti munje noi sruri vo'a ku'o
fo le se nelci be vo'a .i ji'a la'e di'u se zanru dunli ki'u le nu le
stura be le xadni be ro ma'a cu se jinzi le ka go'i ji'a

.i le di'u te zukte cu nu le nu melbi cu se tutci lo'e se jadni purdi
.i le nu makau se tutci cu se jalge le nu makau tarmi .i ji'a .ei go'i
.i .e'u mi'o sruma le du'u drata se tutci ro se jadni purdi fa da po'u
le nu mivycru lo spati .i je'u de'anai purdi .ije makau ni melbi je
za'e tolselpli to mi tolzau le si'o le nu se pluka cu tolselpli kei
ji'u le nu makau ni vajni so'e prenu fa le nu gleki toi .i .e'u mi'o
sruma le du'u le finti cu facki le du'u lo'e spati poi fatne je se
gacri lo canre ca le nu nu'ige le genja le vacri nu'ugi le pezli le
canre cu zvati cu trina fi le ka melbi .i xu fy. za'o te cmene fi lu
se jadni purdi li'u .i na go'i .i ji'a ca le nu ja'a go'i kei lo'e
drata cu da'i na'e tugni ca le nu ji'a vo'a cu facki le du'u melbi .i
la'e di'u se krinu le nu fy. toljundi le se tutci be le se finti be fy
.i ca'o na purdi ji'a

.i la'e di'u se jalge le nu sanji lo simsa be le nu le solri cu carna
le terdi .i ki'unai le nu ro se zukte be le finti bei ca le nu finti
le purdi cu steci se pilno fi le nu galfi le tarmi be le purdi kei le
finti cu zukte le romei le nu rairgau le se tutci be le purdi be'o noi
nu pluka le ganse gi'e zdasabji fi lei spati .i .ui lo'e se jadni
purdi zo'u se tcini le nu ca le nu le du'u makau se tutci cu mulno le
ka se djuno kei le nu makau se tutci cu se jimpe se jalge le nu makau
tarmi .i ji'a le romei cu tugysi'u le du'u go'i .e le du'u .ei go'i .i
.ai mi jarco le nu le nu na tugysi'u cu se tcini so'i da .i ji'a
la'aru'e le nu tugysi'u cu tolcafne gi'enai cafne

.i sei .ei mi cusku mi mutce le ka jinvi le du'u le nu makau se tutci
cu ba'e ro roi vajmau le nu makau tarmi .i seki'unaibo bai le nu ge
piro loi drata krinu cu dunsi'u gi cumki fa le nu finti le tutci be le
mintu be'o poi se tarmi le melmau kei ko gasnu .e'acai .i la'e di'u
simsa le no'u di'e se darlu be la djan. narveson. be'o pe lo'e flalu
ro da poi flalu zo'u bai le nu no de tolkrinu kei ro prenu cu .ei
sruma le du'u da madydra kei gi'eja'ebo tinbe .i so'uroi ku'i cumki fa
le nu galfi le tarmi .enai le se tutci

.i xracmu ke samrxuebe jarco

.i xautce mupli le ka tarmi se srera kei fa le nu zasti ji'a fa lo
xracmu ke samrxuebe jarco poi ca zasti caku .i mi pilno la netskeip.
le nu jarco le tcaci mupli kei ki'u le nu ge ny ja'a tcaci mupli gi mi
na pilno lo se cupra be la MAIkrosaft. to le nu xokau da krinu cu
banzu le nu finti le drata mulno ve pante toi .i lo'e xracmu ke
samrxuebe jarco .e ra'u le nu ri se zanru lo na prije be lo skami cu
romei loi fuzme be le nu catra la .Internet. .i srana ge le nu snoze'a
gi le nu jdika fa le parbi be le se smuni bei le savru

.i le se tutci be le samrxuebe

.i piso'i loi ca nabmi be le samrxuebe cu se rinka lo'e tarmi se srera
ja'e le nu mu'igi jarco le nu makau se tutci gi .ei djuno le du'u
makau se tutci .i le di'u se tutci cu sampu .i le nu pejgau loi datni
.i su'anai le samrxuebe cu mapti le nu punji lo nalcne sa'enai datni
lo nalcne sa'enai stuzi .i va'i do kakne le nu cpacu le stuzi dunli
gi'e pacna le nu tolcri lei datni poi mintu sa'enai lei datni be ca le
prula'i krefu be le nu do sisku zi'epoi la'acu'i gau draze'a .i loi
drata datni poi le samrxuebe cu mapti le nu pilno ke'a cu jonsi'u
datni .i mu'a le nu cuxna lo sinxa be ne'i lo cukta mu'i le nu klama
le se sinxa .i mi pilno la net. co'a le purci be le samrxuebe .ibo
ju'o krasi te pilno le samrxuebe fa le de'u te pilno .enai la'e lu 1EI
zAbna kE lUnbE je MiSN0 pe lA b0B. li'u .i je'a jetnu .i lo prenu cu
je'u ciska lo simsa .i tcaci se cmene zo B1F .i mu'a lu .uaza'a la B1F
noi zabna nanmu cai li'u to le krinu cu bancu le dei ve pante toi

.i ta'onai ki'u le nu le nu pejgau loi datni cu se tutci le samrxuebe
kei mi stidi le nu ro xracmu ke samrxuebe jarco cu natfe le nu makau
se tutci kei ta'i so'i da no'u mu'a le nu vajmaugau le nu makau tarmi
kei le nu makau se tutci mu'i le nu trina lo pilno sepi'o lo'e za'e
zabna pixra .i la'e di'e spaji so'e do .i le samrxuebe jarco so'umoi
cu se jicmu lo'e se tcidu .i je'u ti'e le pamoi cu se jicmu lo'e se
tcidu linji .i ku'i la'e di'u cu srana le tolci'o mutce citri .i le
samrxuebe jarco poi ta'e se pilno mi cu se cmene zo links. gi'e se
tcidu se jicmu ke samrxuebe jarco .i la'e di'u se smuni le nu mi ta'e
na viska lo pixra .a lo tcini pixra .a lo banli lertai .i mi xusra
ki'u le bazi se jarco le du'u la'e di'u xamgu

.i le se notci ku fa'u le tarmi .i slabu ke samrxuebe finti seke darlu
casnu

.i le nu lo'e se notci lo'e tarmi zo'u makau vajmau cu ze'u seke darlu
casnu va'o le samrxuebe finti munje .i ro krasi finti be le samrxuebe
cu ta'e sarji le nu se notci .i ku'i so'u da tolmupli la'e di'u .i le
se casnu cu se krasi le nu makau jinzi la me html ku noi ro da poi
samrxuebe notci zo'u ke'a bangu fi le ve skicu be le stura be da .i la
me html to je'u srana la me html su'e ji'i3.0moi .i ro za'u 2.0moi cu
xlali sa'u toi cu se jinzi le ka bapli le nu le nu makau se notci cu
se jalge le nu makau tarmi to le se notci cu vajmau le tarmi toi .i
mu'a do finti lo barda tcita to no'u le zvati be le krasi be le notci
toi ta'i le nu ciska zoi zoi <H1>ti tcita memimoi</h1> zoi .i le vajni
cu nu na minde fi le nu punji fi le midju ku joi le mumoi linji ku
gi'e jarco sepi'o le zabna barda lertaigri pe me'e makau gi'e skagau
fi le ka xunre gi'e pirci'a lo linji pe ni'a le tcita .i minde fi la'e
lu ti tcita co pamoi jutsi .i .e'o ko gasnu le mapti be du'o do li'u
.i li'a le se notci noi va'o le ca tcini ke'a tcita cu vajrai bapli le
nu makau tarmi .i lo samrxuebe jarco cu jarco sepi'o lei barda lerfu
.a makau .i la links. punji fi le midju gi'e basna vau po'o .i la'e
di'u mutce le ka banzu le nu jungau mi le du'u makau fasnu

.i va'o le nu samrxuebe finti pe le nu le tarmi le se notci cu vajmau
kei do cu .eije'u minde fi le nu tai makau tcita no'u mu'a lu ti midju
li'u noi pinka zi'e ne de'u .i la'e di'u cu se jalge so'i xlali .i
pamai .ei ra'urmau fa le nu makau tarmi le notci kei fe le nu makau se
vasru datni kei .i la'e di'u ta'e se smuni le nu do setca lo mleca
datni .i mu'a ko pensi le dei ve pante .i mi nasa'e bilga le nu minde
fi le nu makau lertai .e le nu makau se skari .e le nu makau tcini .i
mi pejgau lo datni gi'enaicai finti le tarmi be lo cukta .i drata
jalge fa le nu mutce le ka snozengau .i le drani tcita pe di'u zo'u
so'upano lerfu noi se jmina le sevzi be le tcita cu se benji le fi le
samrxuebe jarco noi si'unai jdice le du'u gasnu makau sepi'o lei datni
.i le tcita noi kansa lo ve skicu be le lertai .e le se skari zo'u lo
ba'e linji so'omei cu la'a se jmina .i va'o le nu lo simsa cu pagbu
piro le notci zo'u jmaji .i ma mukti .i le nu ficygau le nu makau
lertai na jmina fi le datni vamji be le notci .inajo le te frica cu
srana le smuni to mu'a lei frica lerfu cu sinxa le drata se notci toi
.i va'o le nu go'i kei do cu .ei cusku fi le samrxuebe jarco fe le se
du'u makau se notci klesi kei gi'e curmi le nu syjy. gasnu .i je'u le
nu ciska lo samrxuebe notci sepi'o lo se notci finti jicmu tadji ta'e
se jalge le nu denmi le ka datni vasru kei gi'e cnici vau ja'e le nu
frili fa le nu cpacu lei datni .i mi jarco lei mi samrxuebe notci noi
mupli ju prane

.i malbra mutmi'i

.i se zanru je xamgu danfu piro la'e di'u fa la'e di'e .i ru'a le
datni cu pixra .i mu'a pixra ja xracartu ja vidni bo pixra .i .ie la'e
di'u smitce le de'u se casnu no'u mu'a le se jdani purdi .i ganai da
mifra le datni le pixra gi srana le tarmi .enai le se tutci XXX .i na
xlali fa lo pixra be va'o lo samrxuebe notci zi'epoi datnyja'o .i le
noi na se nitcu ku'o nu xradenmi fa lo'e ca samrxuebe notci cu
snozengau po'o to .ai snuze'a la'e dei baku toi .i ke'u la links cu
mulno le ka frica ro za'e fadni ke samrxuebe jarco gi'e purci loi za'e
fadni ji'e le se djuno be mi .i la links poi gau tolpo'u cu frati fi
le nu le pilno cu cuxna to ta'i le nu pilno lei farna sinxa gi'e catke
lu'e me'o zukte bu toi lo pixra .a lo sance vreji .a lo skina .a lo
simsa kei fe le nu cfagau le mutmi'i be le nu frati fi le datni klesi
.i .a'adai la'edi'u se smuni le nu la links zo'u na ka'e jarco frati
fi lo pixra .a lo sance vreji .i na nitcu .i guncru lo mutmi'i no'u
mu'a la me xv noi xraja'o ku'o zi'e poi mutce le ka ka'ezma fi le nu
gasnu le se steci jibri

.i la'e di'u mutce le ka mapti la netskeip. le ka ny .ei cilre fo ce'u
.i ny frati po'onai fi loi pixra to .e ji'a la'a loi sance vreji .i mi
naltce co slabu lei cnino toi si'unaiku gi'enai guncru lo drata
mutmi'i poi tutci le nu jarco frati kei gi'eji'a si'unai sabji lo
mrilu tcidu mutmi'i .e lo nuzba tcidu mutmi'i .i .uenai le nu ny.
cfari va'o lo'e vlipa skami cu mentu li mu .i je'e do le selskicu cu
dukse .i ku'i na'e mutce .i da mutmi'i sutmau fi le ka mrilu jarco kei
gi'e se tcila lo zmadu .e lo selplimau gi'e cnici ta'i lo xagmau .i
mi'u la nuzba pe la'o zoi USENET zoi .i .iacaidai la nuzba zo'u .ei
sutra .i lo'e pixra ji'a zo'u la netskeip. ka'e se sidju .i ca le nu
la me xv jarco lo pixra kei mi ka'e pilno py. so'i da .i mi ka'e pilno
fi le nu vanbi pixra kei gi'e ficygau ja'e lo vrici to le nu xulgau .e
le nu kilgau .e le nu ctile cinta pixra mlugau toi .i mi kakne le nu
brazengau .e le nu cargau .e le simsa .i va'o la netskeip. zo'u mi
kakne le nu ...y. vrejyfi'i gi'e prifi'i .i ca le nu mi nitcu le nu
gasnu lo lujmau kei mi bilga ji'a le nu finti le vreji .i di'u claxu
le nu cusku le se du'u lo'e xraja'o se tcila cu sutmau fi le ka jarco
kei fe la netskeip. pe ka'eku

i le nu lo mutmi'i cu ta'e binxo lo malbra dukse rigni cu mutce le ka
srana lo'e tarmi se srera .iape'i .i lo prenu cu se raktu le nu lo
drata mutmi'i to poi seke pilno tadji lo frica milxe toi cu tolcanci
ca le nu gasnu da kei va'o ji'a le nu le mutmi'i cu matmau fi le se
gunka .i va'o ji'a le nu pilno le drata mutmi'i cu sutyzengau le skami
to ni'i le nu ro pamei je bratce mutmi'i cu snomau roroiku toi .i le
pilno na kakne co jimpe le du'u to simlu toi taicne kei .i seki'unaibo
le nu taicne cu jinzi se kuspe le nu makau se tutci le skami .i ga'i
bebna

le ca nunmle ranmi zo'u morsi ri'a le nu makau tarmi

.i le ca nunmle ranmi cu pe'i bratce se fliba lei sarji be le si'o
dunli .i lo drata cu go'i ji'a .i la'a mi ba tavla la'e di'u su'oroiku
.i noroi co'u macygau mi fa le nu lo'e stici ninmu cu mulno co zanru
pixokau loi tolma'u ke nimxei fenki ca le nu jersi le ka za'e melbi

.i le se sanji traji se ckaji be le di'u ka sezyxei to le nu sezyxei
ca nu jersi le ka melbi .i ji'a le jamfu tagbakfu .e le nu nimpinji
katna va'o lo drata kulnu toi cu ka de'anai jersi le ka cinla .i ca'o
le nu mi jmive kei mi so'iso'iroi tavla lo nanmu loi cinla dukse ninmu
.i piso'e loi nanmu poi mi tavla ke'a cu tugni mi le du'u lo'e
nanlysmi je cinlydu'e ninmu poi ca gunka va'o le taxfu jarco gundi pe
le munje cu do'a no'e melbi gi'e to ju'o du'o mi toi mulno le ka
toltrina do'anai .i mi cusku di'u ki'u le nu ma'i le sidbo .u lo drata
piro le krinu be le nu melbi cu nu trina lo cinpe'o .i mi zukte le nu
naltavla fi loi duncinse joi rolmeicinse joi ficycindasni .a le simsa
ki'u le nu le nu le cecmu cmima su'a cu pensi cu banzu le nu
xagmaubi'o le noi se bapli tu'a le cecmu ku'o nu sezydaspo noi so'isai
ninmu to .e so'isai nanmu ji'a su'oroiku toi cu tarti ke'a ca ro djedi
be ca le nu jmive

.i ja'o va'o le nu mutce le ka cinla ta'e na trina lo'e nanmu kei to
.ije ji'u le lisri se lifri be mi na trina .i ku'i ko pensi lo'e
cingau karni mu'i le nu birti toi ma cai mukti .i .a'u ba'e mi zo'u na
djuno .i ba'e preti fi mi .i le mutce co raktu be mi cu nu ca mutce
tolzau ro milxe bi'i mutce le ka rotsu .i sera'a lo'e zmadu mi milxe
co jimpe .i le nu cinlydu'e ne pa'a le nu tsudu'e na banro .ije lo'e
prenu cu milxe cuxna le speni ja'i le nu makau ze'u jmive sa'enai .i
ku'i va'o le di'u se ranji ro ninmu cu ka'enrai fi le nu snura se
jbena .i la'acu'i je'a krinu le nu le nu makau se nelci cu cenba va'o
lei stici cecmu ca'o le prula'i ctona'a be li so'o .i le remna jutsi
cu nitcu le nu le se klani be piro loi jbena cu cmatce .ija'ebo ma'a
nalsanji cuxna loi speni noi jdika le ka ka'e verba cupra .i va'o le
nu go'i kei mi sinma le nalselsanji se jdice gi'e ku'i mojgau fi le
du'u simlu le ka na kanji sanji lo nalseljbe tadji to la'acu'i ki'u le
nu so'e prenu cu mutce le ka bebna le nu na pilno tadji djuno

.i ku'i da pe le nunmle ranmi cu zmadu fi le ka raktu mi kei fe lo'e
cinlydusterbi'a .i pa le go'i cu me la'e di'e .i loi nanmu cu ja'aru'e
mulno le ka fuzme le nu finti le nunmle ranmi kei .ije zu'unai loi
ninmu cu mulno le ka zanru .ije lei nimdunsra cu mulno co fliba le nu
fuzme fapro le nunmle ranmi .i mi frati fi ro le nu go'i kei fe le nu
cusku lu ki'a mabla li'u po'o gi'e co'u pensi .i le besna be mi cu
tolsarxe le nu cnici pensi lei di'u fatci .i ji'a mi na djica le nu
troci

.i drata vajni mi fa lo'e jmazbe lafti cutci .i lo'e go'i sei so'e
ninmu poi dasni cu cusku cu cmatce crogau minji .i ku'i loi ninmu cu
co'unai dasni gi'e ralte le nu cortu tai le nu lo gerku cu ralte lo
ciblu joi rectu ricfu bongu mu'inai le nu vasru lo dakfa poi ca'o
zalvi lei ctebi be le gerku .i lu ku'i trigau mi li'u se kixsku lei se
gunma ninmu .i ja'o mo .i ta'i ma pe ka'eku le vamju be le di'u nu
cortu cu banzu .i ju'o go'i ki'u le nu ro se viska jalge be lo'e
jmacmu lafti cutci be'o poi se sanji ba'e mi cu nu lafti le zargu ja'e

.i romai lo'e tatsra taxfu .i tyty. cu mulno le ka to'e se jimpe mi .i
