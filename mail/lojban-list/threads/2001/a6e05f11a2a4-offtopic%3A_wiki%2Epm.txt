As part of the Elephant project, I have written a Wiki-markup
to HTML interpreter in Perl, used thus:

use Wiki;
$/ = undef;
my $text = <>;
my $html = Wiki::interpret($text)

All the usual Wiki conventions (except links that are not in
square brackets, like freestanding URLs and WikiWords) are
supported.  The generated HTML is valid XHTML, provided
you wrap it in "<doctype html ...><html><head><title/></head><body>"
and "</body></html>".

This is Open Source (BSD) code.  It would be easy to translate to
any other language with a decent regular expression package.

Drop me a line if you want the code.
