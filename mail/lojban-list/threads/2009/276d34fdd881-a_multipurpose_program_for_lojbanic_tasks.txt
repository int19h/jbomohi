A multipurpose program for lojbanic tasks

Author: omologos

During this vacations I wrote several modules in python which I have now put into a command-line program to analyse lojban text and some other things. I've tentatively named it {jbofi'egri} in reverence to Richard Curnow's excelent set of tools.

Currently, jbofi'egri is able to do several of the tasks I previously did with the help of lojbot:

jbofihe: which simply passes the given text to jbofihe, which must be installed. I have got version {V0_38}.

jvofinfihe: Which uses the jvocuhadju tool included with jbofihe (I gave all of the commands fishy names).

luvyfihe: which analyses lujvo and lujvo-like names giving the corresponding gismu. A task known as {lujvo} in lojbot.

matyvlafihe: which looks out for glosses of english words or phrases.

bahurfihe: which makes the computer speak out a given text. It uses espeak and it probably requires AOSS to be installed.

I would like to release the program (probably GPL-ed) for others to use it and hopefuly improve it, but I don't know how to make it available. 

Suggestions? Comments?

P.D. Now that lojbot as well as jbotcan are down I can't compare the results of my software with those of lojbot. I did the whole thing thinking of the convenience of having this kind of software ofline.

P.P.D. I've learned that donri has writen another IRC bot for this kind of tasks ("makfa"). Do you people think it's better to stick with the IRC bots? Am I foolish to think someone might use my software instead of bots?
