"eSpeak" is an open-source TTS with a lojban voice which you can
experiment with:

http://espeak.sourceforge.net

The name of the lojban voice is "jbo".

The current development version has a few improvements. It is at:
http://espeak.sf.net/test/latest.html

If you have suggestions for corrections, please tell me.

eSpeak uses formant synthesis and therefore the quality is not as good.
 However, eSpeak can also be used as a front-end for "mbrola" diphone
voices, which sound more human.  Perhaps you find one which has the
necessary set of phonemes for lojban.  Information on eSpeak + mbrola
is at:
http://espeak.sourceforge.net/mbrola.html
