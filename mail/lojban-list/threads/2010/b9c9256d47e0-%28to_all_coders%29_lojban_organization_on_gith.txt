Hello fellow sampla,

I took the liberty to create a free organization on github called
"lojban" and I added the first few people who turned up in a search for
"lojban". I'm hoping to get all lojbanic projects on github in one place
to increase visibility, awareness, collaboration and synergy effects and
all that. If you are not yet on github, consider joining and managing
your lojbanic code there, it's pretty neat. You can mail me your github
username and I will add you to the organization.

I would also be incredibly happy to get either a discussion among coders
started or an entirely new mailing list for lojban programmers, so that
"normal people" don't get bothered by techtalk.

Please tell me what you think.

Git is completely content-type agnostic. It works best with plain text,
though, so if your files are in that format, great! I must warn you,
though: the last time I checked, windows software for git wasn't that
nice. (for mac, though, there's lots of cool stuff), so the barrier of
entry might be somewhat higher for windows users. Editing files that are
already there is possible directly in the github website, though, so
maybe it's not all that terrible? I encourage you to investigate, while
I try learning for my exam tomorrow ;)


> If that's the case, git may be a better place for future projects due
> to accessability and the way things can be edited/merged, plus it
> adds to your visibility factor.

It really depends. If you have plain text files, then yes, merging and
editing those with git (even directly on github) isn't very hard. Much
of that is due to the fact that you can easily review plain text diff
files. Diffing binary files (images? sounds/music?), not so much.
