Now there is full dictionary of Lojban based on Lojban Wikipedia and
jbovlaste.

There is a program called GoldenDict [http://goldendict.org/forum,
also see http://en.wikipedia.org/wiki/GoldenDict]

It's free dictionary software to say in short.

There are currently several dictionaries exported from jbovlaste.
Also there are three dictionaries "rupnu", "gugde", "bangu" converted
from
lists proposed by Jorge Llambias and Leo Molas
[see http://www.lojban.org/tiki/tiki-index.php?page=What%27s+New%3F#4July2010]


INSTALLATION FOR WINDOWS operating system.
1. Download this file
http://rapidshare.com/files/415675035/goldendikt.7z
2. unpack it (using 7-zip, look at http://en.wikipedia.org/wiki/7-zip
for more info)
3. Run GoldenDictPortable.exe file. Goldendict will index the
dictionaries (it will happen only once).
4. Goldendict window will appear.
Type in any English word or jbovla. You can type part of the word,
e.g. "ban" and determine which glivla and jbovla have that sequence at
the beginning.
GoldenDict searches in Lojban Wikipedia and Wiktionary by default. By
you can turn off those by pressing corresponfding icons in the
toolbar.

LANGUAGE OF INTERFACE
It's set to English by default. But can be changed to Chinese, Arabic,
German, Russian in settings (hit F4). Have time to translate to
Lojban ? I'll tell how (if somebody asks).

INSTALLATION FOR Mac, Linux and Nokia Symbian OS.
Look at http://goldendict.org/forum
You can find latest builds for Mac and Linux there. Not sure about
Nokia smartphones but as the program is written in Qt and is open-
source the solution can be found.

ANY QUESTIONS ?
Please write them either here or at that forum.
