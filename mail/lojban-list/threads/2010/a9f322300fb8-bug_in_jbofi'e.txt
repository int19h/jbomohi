  Right, because it's behaving as if "bjo" is a valid rafsi formation.
 (For example, compare the way it handles "nalce'e/selce'e")  It knows
that nal- means "other than f" where f is the gismu of the second
rafsi, so it can say that part even if the second rafsi is undefined.
But SE conversions it can't do unless the rafsi is actually pointing
to  a real gismu because the x2 's gloss is completely
gismu-dependent, so those just return "???".  (just like it can say
"grace'e" is "weighed in grams -???").  What is SHOULD be saying is
"unrecognized word", just like "grabjo" gets you.  It obviously has
special code for certain beginnig rafsi.

                        --gjeyspa
