Yes, look here. https://sites.google.com/site/slovlacukt/file-cabinet
Download the latest jbo.7z archive. An EmEditor script that converts
exported database to .dsl format is qinside that archive. But manual
cut'n'paste operations are still needed after the conversion.

Also I noticed several bugs of export functionality of jbovlaste.
1. E.g. two different jbovla have the same English glossword. Then in
English-to-Lojban part of the TeX file glossword points only to one of
that jbovla.
2. Etymology, examples and comments are not exported.

Can anybody tell how to export jbovlaste completely ? E.g. to
some .sql  file or so ?
