http://groups.google.com/group/lojban/ is where you go, and there is a 
link on the right for "edit my membership", where you can select digest 
or even no-email if you want to only read online.

To do this, you may need to log in using your subscribed email.  If you 
never had a Google account under that email, you may need to have them 
send you a password.

There is a help link at the top of the page.

There are multiple ways to display messages online - latest or all 
messages, threaded or non-threaded.  If you select a thread to read, 
then there is an "options menu" on the bar with the thread title that 
lets you choose fixed or proportional spacing, and "standard" that shows 
the full text in order (hard to find a particular message) or a tree 
view that shows the whole thread and the text for 10 messages at a time, 
making it easy to find a particular part of the thread.

There is a search function for the archives, but I've had spotty 
success.  There is an "advanced search" link on the main "search groups" 
page which might work better.
