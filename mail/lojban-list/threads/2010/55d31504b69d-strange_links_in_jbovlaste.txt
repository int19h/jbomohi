coi do'o,

I found some gismu in jbovlaste had broken references ( for example
xexso, which said 'cf blah blah blah blah blah blah blah blah blah...'
in the notes, but the references weren't properly {bracketed}). I'm
sure there are more, but I've fixed them.

I've also found there are some valsi referring to {causal} and
{resultative} -- IMO these should not be {references} -- unless we can
link to an article on the wiki describing the difference between them,
or something similar.  (an instance of this  is the entry for {stika})
Is it appropriate to remove the {bracketing} from them so they don't
come up as links?

I found these when making a little script to use makfa to build a
graph of the relations between lojban valsi. It's not quite ready yet,
but I plan to post the results somewhere soon.
