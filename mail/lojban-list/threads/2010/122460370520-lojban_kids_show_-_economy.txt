I'm going to write a page about the economy. I've been thinking about coins, 
and about making them of copper, titanium, silver, gold, and palladium. The 
first four, I think, would have prices in about the same ratio as on Earth, 
but with palladium I'm not sure how to compute. Palladium absorbs hydrogen, 
which makes it highly desireable in Lobgugde, where the primary fuel is 
hydrogen. So I thought it would be way more expensive up there than here. But 
I looked it up; it's used primarily for catalytic converters, which wouldn't 
be used in Lobgugde because there's no petroleum up there. So would it make 
sense to make coins of palladium, or would it all be used in hydrogen stores?
