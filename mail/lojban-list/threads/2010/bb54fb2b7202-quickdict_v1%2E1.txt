While I continue to screw around with python and making QuickDict
multi-platform, I've thrown together a V1.1 to fix some of the issues
brought up about V1.

For your convenience I've copy+pasted the change notes below:

V1.1 - 11/02/2010
       added 3 different "modes" for closing the definition window.
       added support for cmavo clustering.  If something like "roroi"
           is encountered, QuickDict will now look for an entry for
           "roroi" in cmavo.txt
       added multi-line support.  Now definitions won't take up three
monitors!
       added a feature to settings.ini.  Now you can tell QD to ask vlasisku
           for what it thinks of a lujvo (and still tell you the component
gismu)

v1.0 - 10/30/2010
       Initial release



I didn't put it in the notes anywhere, but the feature to go ask vlasisku
about lujvo definitions is disabled by default.  It's still an experimental
feature (but do give it a try and let me know how it works for you).  Again,
any and all feedback is welcome.  Thanks.

Oh, the link to the new version: http://www.filedropper.com/quickdictv11

Well,unlike the previous version, I am actually able to test this one. :)

- It crashes if you press the keycombo without anything selected - you
should add code to handle that error.

- I haven't really tested out the vlasisku lookup, but I tried a few
different lujvo, both defined and undefined, and it is nice to see the
definitions - I would, however, put the actual definition after the the root
word listing for consistency. (So {fu'ivla} would return

"From: fukpi: copy | valsi- word

x1=v1=f1 is a loanword meaning x2=v2 in language x3=v3, based on word x4=f2
in language x5.

instead of the other way around as now.)

- Can you get rid of the other two buttons? Only the [x] close button really
needs to be there.
- - On that topic, the window itself seems too long. It would be nice is the
window adjusted itself to the dimensions of the content.

- The multiple line thing is nice, but the first line is always blank. This
seems to me to be a waste of space.


All in all, so far I like how this is coming.
