I have created an experimental web service on the Jorne site. It uses  
Robin's PEG parser to create an XML parse tree based on Lojban text.  
It's not particularly tolerant of errors in the text - did I mention  
experimental? ;-) - and the output tree is not much to look at. Its  
purpose is not to be displayed directly, but to embed within  
Javascript calls for Lojban mashups.

There is a web form that you can use to see how the service works.
http://jorne.org/form.jsp

The easiest way to build something on the XML result is to apply an  
XSL stylesheet that does some highlighting or text outlining. You are  
welcome to call the service from your own web site as long as it  
doesn't overwhelm the service with too many calls. I plan to make a  
stylesheet to pretty-print something better when I have some time.

What will you build from it? Have at it, Lojban web developers!
