As I explained in previous mails, I think each terbri (and
gadri, and sumtcita, and some other cmavo) have a collection
of features, which can be used to determine some sort of
categorical consistency of sentences. Here is my first attempt
at assigning some. I'm sure it will be much modified. It
covers bacru to benji.

        Colin


Tentative list of features.
==========================
Some of these I am sure are useful, others I put in because I
thought they might be, but they may turn out not to be.

Some features imply others (or the absence of others)
Where an implication is specified,
both need not of course be specified explicitly for a terbri,
but sometimes they are both specified in the list below for
clarity.
I think that +set is incompatible with most other features
(not all), but I think there might be value in allowing '+set
+feature' where the '+feature' applies to members of the set,
so I have put these in sometimes, in parenthesis. Only
practice will tell whether this works.

abstract        - abstraction (-> -concrete)
activity        - (-> +event)
animal          - (-> +bio)
bio             - biological
concept         - concept (-> +abstract)
concrete        - concrete (-> -abstract)
emot            - (capable of) emotion
event           - (-> +abstract)
kind            - species or sort (-> +abs)
location        -
mass            - is (treated as) a mass. Is consistent with most other
                        features, which may be inherited from its components.
pers            - personal (not nec. human)
plant           - plant (-> bio)
property        - (-> abstract)
proposition     - (-> abstract)
purpose         - (-> abstract)
set             - is a set
shape           -
standard        - (not nec +abstract)
state           - (-> +abstract)
substance       - (-> concrete)
text            - text (not nec written) (-> +abstract)
vol             - volitional

^: unspecified (sometimes mentioned for emphasis)
?: I'm not sure whether this feature is there, usually because
I'm not quite sure of the meaning.
