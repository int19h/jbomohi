I have prepared the following TeX versions for a mixed Lojban
word list (the latest gismu list, cmavo list, rafsi and the
jvoste by Nick Nicholas) and uploaded them to casper.cs.yale.edu
/pub/lojban/incoming:

    dict.lj.Z      HP Laserjet version, compressed
    dict.ps.Z      PostScript version, compressed

    dictdemo.lj    a demo page
    dictdemo.ps

They are for single-sided printing, with a page size also
suitable for American paper sizes. The complete versions
produce 248 pages, so you had better try the test pages
first to see whether they are satisfactory.


If you are printing the Laserjet versions under MS-DOS,
remember the /B switch, i.e.

   copy /B dictdemo.lj lpt1

(otherwise you'll get a partial print-out only)

I had to do some manual tweaking after transforming the
original word lists with AWK and there just might be some
slight inaccuracies. So beware.

The printed version looks quite presentable and I have
found it quite handy to have all the lists alphabetized
together. The omission of the leading period from the
vowel initial cmavo was based on aesthetic considerations
-- I tried it both ways.

I can prepare versions for 2-sided printing (thickness of
the paper stack reduced to < 0.5") and/or DIN A4 paper
size (page count will be reduced to 223). I can also
provide the TeX source files on request.
