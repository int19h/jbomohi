Hello all,

zmifanva is a Lojban-English machine translation engine developed by Masato 
Hagiwara a few years ago. I've containerized the code and now it's possible 
to run the tool locally:

```
wget 
https://raw.githubusercontent.com/olpa/lojban-mt/master/zmifanva/docker-compose.yaml
docker-compose up
```

Zmivanfa works on the port 6543. Open the start page in your browser: 
http://localhost:6543.

The containerization source code and other ways to run zmifanva are here: 
https://github.com/olpa/lojban-mt/tree/master/zmifanva

Enjoy,
Oleg
