As discussed in another thread, I did not found ready-to-use dictionaries 
for common software. So I began tweaking... and finally prepared some *very 
basic* (Hunspell-based) dictionaries, for LibreOffice / OpenOffice, 
Firefox, and Opera : https://github.com/Sukender/lojban-spell-check-dist

Please test and give feedback!

If you need tools to generate those dictionaries, you may check 
https://github.com/Sukender/lojban-spell-check
And of course, if you want to improve / comment / help, or if you find 
resources or better dictionaries, please go ahead and share!
