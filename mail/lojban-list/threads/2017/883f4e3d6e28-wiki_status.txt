I've made a container for the Lojban mediawiki, so we'll have
more flexibility in upgrades (both that we can avoid them, and that
we can do them more easily when called for).

The server-side administrative instructions are at
https://github.com/lojban/mediawiki-docker , should anyone like to
help with that part.

Here's some notes on things that people who actually
*use*/administer the mediawiki might want to fix/know:

Extensions that are no longer supported:

- HideVariousTabsFromUnauthorizedUsers
  - There's a note in LocalSettings.php that relates to this and may
  be relevant:
    //$wgGroupPermissions['*']['edit'] = false;//must be disabled by  HideVariousTabsFromUnauthorizedUsers extension 
- Mantle
- RandomText
  - can be replaced with RandomArea, but I don't know where it's used
- UniversalAnalyticsIntegration
  - google literally has no idea what this is/was
  - seems to have been Google Analytics; gleki handled this some
  other way
- GoogleTagManager is therefore irrelevant, probably?

Significant upgrades:

- DynamicPageList is now https://www.mediawiki.org/wiki/Extension:DynamicPageList3
- Metrolook is now https://github.com/wikimedia/mediawiki-skins-Metrolook/commit/f2ec55b5929784d3aa9262c551db66777d33c32a

Additions:

- Vector Skin
