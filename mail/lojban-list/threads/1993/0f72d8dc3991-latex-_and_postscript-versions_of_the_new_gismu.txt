I have placed a LaTeX version of the latest gismu list (gismu.tex)
to the /pub/lojban/incoming directory at casper.cs.yale.edu.
This file contains no formatting commands.

There are two auxiliary LaTeX scripts (ldict.tex and ldict2.tex)
which contain the formatting commands for either single or
two-sided printing (DIN A4 only, sorry). These scripts input
the gismu.tex file.

ldict.ps.Z is a compressed Postscript version of the list.

I also uploaded the awk script which I used to prepare the tex-file
from the raw gismu list (gismutex.awk).
