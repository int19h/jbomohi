I am starting a regular monthly posting on how to use Lojban List.

1) To post a message to Lojban List, send it to <lojban@cuvmb.cc.columbia.edu>.

2) To remove yourself from Lojban List, send a message to
<listserv@cuvmb.cc.columbia.edu> whose body consists of the single line:

        unsub lojban

3) To temporarily suspend your subscription to Lojban List, send a message to
<listserv@cuvmb.cc.columbia.edu> whose body consists of the single line:

        set lojban nomail

4) To resume a suspended subscription, send a message to
<listserv@cuvmb.cc.columbia.edu> whose body consists of the single line:

        set lojban mail

5) For help, send mail to <lojban-list-request@snark.thyrsus.com>.

6) Basic information on Lojban is available via anonymous FTP at
casper.cs.yale.edu:/pub/lojban.  The README file may be retreived as
follows from most systems (your mileage may vary):

        % ftp casper.cs.yale.edu
        Enter username: anonymous
        Enter password: yourname@yourhost.domain (does not echo)
        ftp> cd pub/lojban
        ftp> get README
        ftp> get README2
        ftp> bye
        %

8) Technical Lojban terms frequently used on Lojban List:

        cmavo - little word, structure word
        brivla - content word, predicate
                gismu - root word, prim, primitive word
                lujvo - complex, compound word
                le'avla/fu'ivla - borrowing
        bridi - statement, predication
        selma'o - word-category, "lexeme"
        tanru - modification pair, metaphor
                seltanru - first element of tanru, modifier
                tertanru - second element of tanru, modificand
        rafsi - affix, bound morpheme
