Robert Chassell sent me a report on compiling the parser with GNU CC.
The file "lojban.h" makes reference to a standard header <malloc.h> which
does not exist on ANSI C systems.  The correct ANSI C equivalent is
<stdlib.h>.  Making this change should aparser to compile
successfully with "gcc -traditional -o parser *.c".
