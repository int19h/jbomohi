Haven't followed the thread closely, but to express ASCII codes in Lojban,
we have expanded se'e (which used to be IPA shift) to be a generic code
marker.  Thus se'ezebi (gramamtically a number - use "li" or "me'o" to get
it into a sumti as value or symbol) would express ASCII-78 provided that
the current default code set is ASCII.
