This is a repost.  My apologies if you get it twice.

The second draft of the Lojban textbook, >Bootstrap Lojban<, is now available
by anonymous FTP at casper.cs.yale.edu:/pub/lojban/draft/textbook/lesson??.unf.
(See the end of this message for detailed retrieval instructions).

This represents unedited text, and is full of queries and "***" markers
indicating that something is unfinished or incomplete.  Everyone interested
in Lojban who has some time available is urged to look at the material, as it
is intended for people who wish to learn the language from scratch.
The more constructive criticism we get, the better the final product will be.

All files are converted from their native Microsoft Word for Windows 2.0
format to plain ASCII text, but line lengths are typically about 110
characters.  Much formatting information has been lost.  On request, I can
post the original or the Microsoft RTF format.  (Please don't request these
unless you intend to really USE them, as it will take some time and effort on
my part to convert and upload.)

The file lesson01.unf is the longest, containing Lessons 0 and 1.  This
material has never been published.  The remaining files contain the
substance of the old published draft textbook lessons 1-6, with much
reformatting and many revisions of details to bring them up to the
current language.  A few sections are yet to be rewritten.  Each old
lesson has become 2-4 new lessons, so the lessons are much shorter.

To retrieve using ftp (details may vary):

ftp casper.cs.yale.edu
Name: anonymous
Password: your-email-address@your-site.domain
ftp> cd /pub/lojban/draft/textbook
New directory is /pub/lojban/draft/textbook
ftp> prompt
Interactive mode off
ftp> mget lesson??.unf
(much noise indicating retrievals in progress)
ftp> bye
