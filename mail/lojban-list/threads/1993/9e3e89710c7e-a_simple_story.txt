Here is a simple story consisting mostly of rather easy sentences.
I have tried to exploit only the basic place structures and a few
relative phrases and clauses of which one is preposed:

   lo goi ko'e barda gerku = lo barda gerku goi ko'e

I didn't have any plan when I started writing so all the details
do not hang together very well. I have run the text through
the parser and checked that it parses the way I intended it to.

ni'o sance
.i mi tirna le sance le zgike
.i mi klama le canko lamji
.i mi canko catlu le bartu be le dinju
.i mi viska lo nanmu goi ko'a le bumru
.i ko'a cu sutra klama le vi dinju le tcadu le jibni ke tricu foldi
.i ko'a kansa lo goi ko'e barda gerku le nu cadzu le dargu be ti
.i ko'e se nelci mi poi catlu le nu ko'e xutla cadzu le le dargu ku
   cilmo canre
.i mi roroi nelci lo melbi gerku poi mi viska
.i mi catlu le nu ko'i goi ko'a .e ko'e cadzu
.i ko'i zvati le mi purdi vorme
.i ko'i sisti le nu cadzu kei gi'e carna fi le srasu foldi poi pritu
   le dargu mi
.i ko'a cpacu lo cmalu ke mudri grana gi'e renro ri le foldi
.i ko'e sutra ke bajra cpacu le grana le stuzi poi ri farlu
.i ko'e bajra klama ko'a gi'e dunda le grana
.i ko'e cadzu klama le foldi gi'e carna fi ko'a
.i ko'e denpa le nu ko'a renro le grana kei le za'i mutce cikna
.i ko'a muvdu le grana le pritu xance le zunle xance gi'e
   go'i fi ri ra
.i la'edi'u rapli
.i go'i
.i ko'e denpa fi le za'i xanka
.i ko'a renro gi'e carna fi le dargu gi'e co'a cadzu
.i ko'e cpacu le garna gi'e carna
.i ko'e sutra bajra jersi ko'a
.i ko'i masno klama le tricu foldi
.i mi tirna noda le zgike
.i smaji ti

    co'o mi'e veion
