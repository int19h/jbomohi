'innate'.  There seems to be some sense that an innate ACTION is something
different than an innate STATE or PROPERTY, but I'm not sure what it is.

tarti (is a predisposition a behavior or can it result in a single type

pattern of behavior.  Hmm. Maybe it is a rarna xlura or a jinzi xlura, which
