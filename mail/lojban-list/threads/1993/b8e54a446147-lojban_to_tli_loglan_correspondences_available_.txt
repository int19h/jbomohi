I have just uploaded to the Lojban ftp server on casper.cs.yale.edu
in directory /pub/lojban/draft
the file oldlog.txt

This file contains a draft appendix for the forthcoming Lojban dictionary
reference setting forth correspondences between the Lojban gismu (root)
list and the corresponding lists for other published versions of Loglan,
especially the 1974-5 Loglan dictionary, the 1983 "GMR" revision, and
the 1989 edition of "Loglan 1".

The file relies haeavily on the Lojban gismu list, which a version is
in the /pub/lojban directory as logdata.raw  I expect to have a new
version of this file incorporating many notes reflecting the comparison
between the Loglan versions, within a few days.

Comments are welcome.  I am also circulating this into the TLI Loglan
community in hopes that they will behelping to ensure that this list is
accurate and up-to-date, as well as to test the possibility for peaceful
cooperation in the Loglan Project in the future.
