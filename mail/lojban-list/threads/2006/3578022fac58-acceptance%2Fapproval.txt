These are the glosses proposed in
<http://www.lojban.org/tiki/tiki-index.php?page=BPFK%20Section%3A%20Realis%20Attitudinals>:

.i'a (UI1)
Attitudinal. Used to express acceptance / acknowledgement / admission
/ assent / consent / acquiescence / conformity / satisfaction (cf.
selmansa, nalpro, no'epro, nalzugjdi, fi'i)

.i'a ta banzu
Okay, that will do.

.i'e (UI1)
Attitudinal. Used to express approval / endorsement / sanction /
support / approbation / favor / praise / applause / acclaim. (cf.
zanru)

.i'e do xautce gunka
Very good! You did an excellent job.


mu'o mi'e xorxes
