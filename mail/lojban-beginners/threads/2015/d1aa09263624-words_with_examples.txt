http://tatoeba.org Note that examples there are not guaranteed to be
correct since they can be added by literally anyone.
For you a purely Lojbanic tool has been prepared, named la muplis:
http://mw.lojban.org/extensions/ilmentufa/i/muplis/index.html

It uses the same tatoeba.org database.

Another resource is
http://mw.lojban.org/papri/La_Bangu:_Lojban_Dictionary_with_Examples

To search in this dictionary you might want to use la naxle tool:
http://mw.lojban.org/extensions/ilmentufa/ircbot/naxle.html (use La Bangu
button there).
