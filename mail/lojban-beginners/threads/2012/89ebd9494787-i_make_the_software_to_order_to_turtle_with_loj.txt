coi rodo

http://homepage3.nifty.com/salamander/myblog/cakyrespa.html

I make software that draw picture.
This is like LOGO Turtle.
LOGO is programming language.

It's alpha version.
I will make it better.
This software use the parser library that I write using Pappy.

You can order to turtle.

ko crakla -- It go forward
ko rixykla -- It go backward
ko crakla la'u li renono -- It go forward 200

ko carna -- It rotate
ko carna fi lo pritu -- It rotate rightward
ko carna la'u livomu -- It rotate 45 degrees

ko bagi crakla gi carna -- It go forward and turn left
lonu ko bagi crakla gi carna cu rapli li vo -- It draw rectangle.

ko pilno lo penbi poi pelxu -- The line which it draw becomes yellow.

You can repeat about each values by following.

bagi lo xunre gibagi lo crino gibagi lo pelxu gi lo blanu zo'u ko bagi 
pilno lo penbi be ce'u gi crakla
 -- It draw red, green, yellow, blue colored lines

It can remember tasks.

.i ko morji lines bu goi lonu ko crakla la'u ce'u
.i li cinono zo'u ko gasnu lines bu
 -- It draw line which length is 300

And so on.

Please try it.
If you use Windows, download cakyrespa-0.0.23.exe and glut32.dll and move 
these files to same folder.
And run cakyrespa-0.0.23.exe.
You will see two windows.
Please input command to console window, then turtle run.

If you use Gentoo Linux, I prepare layman repository.

Or if you know Haskell well, you can use cabal to install it.
If you have Haskell platform, you can install this program with the command 
"cabal install cakyrespa".

ki'e mu'o
