On Monday, April 30, 2012 03:16:25 jongausib wrote:
> I just wonder if it's possible to have lujvo as prefix for fu'ivla.
> 
> For example: I guess "nanba" include all kind of things you can make

> do with a cake/pastry, not a brown bread, could you construct the
> fu'ivla "titnanbrsemla"?

No. A type-3 fu'ivla has only one rafsi classifier. I don't know what the 
counterexample is, since not I figured it out, but if you try to use two rafsi 
prefixes in a type-3 fu'ivla, you can run into trouble. "titnanbrsemla" is a 
type-4 fu'ivla.
