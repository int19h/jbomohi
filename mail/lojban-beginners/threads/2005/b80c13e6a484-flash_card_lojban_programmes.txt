Actually this comes right after a thread about flashcard programmes for
linux.  Some software is mentioned at
http://www.lojban.org/tiki/tiki-index.php?page=Software&bl, I don't have
a Mac so I don't know which of these are good.
I personally like jMemorize http://www.riad.de/jmemorize/ which is made
in Java+Swing so it should run on Mac too.

The converted supermemo list for jMemorize is here:
