SuperMemo 98 is also available as freeware (the link is at the bottom of the 
SuperMemo 7 page), and runs well on XP.  It took some floundering around to 
figure out how to import the .txt file, but I finally managed it.

Download SuperMemo 98, unzip it, and copy the complete set of files to some 
folder (you don't need to run a setup program - a straight copy of the files 
will work).

Download the .txt file from the lobjan.org software page.

Run SuperMemo (double-click on sm98.exe).

Go to File --> Level  and choose "Basic"
Go to File --> Level and choose "Professional"
(Yes, you have to do this twice - "Professional doesn't show up on the menu 
until you've chosen "Basic")

Go to File --> Import and choose "Q'n'A Text", then click [OK].  The file will 
import correctly.  You can then simplify the display by going back to File 
--> Level and choosing "Beginner".

Okay; this is getting really hard /bau la lojban/. Supermemo 7 (the free 
version) was written for Windows 3.11. Back in those bad old days, 
filenames used to be of the form xxxxxxxx.xxx - where x is any character 
- that is to say, only 8 characters long with a 3-character extention 
(e.g. "winword.exe"). You need to rename big_list_supermemo_win.txt to 
something much shorter to get it working (e.g. "lojban.txt", or even 
just "lojban"), even if you're using Windows XP.

I have to apologise on behalf of all programmers worldwide for the
