Hello fellow lojbanophiles,

Here's a Linux (Python) equivalent of Parallel 2 "a FREE program for 
parallel reading and listening in two languages" by Yanis Batura.

http://www.lojban.org/tiki/tiki-index.php?page=Parallel+2&bl

I use Linux, but Parallel 2 doesn't run on Linux, so today I wrote this 
fast hack which incorporates the display method used by Michal 
Wallace in Learnfast. You need to have Python, Pygame and RealPlayer 
installed (and the Parallel 2 data files of course).

Any suggestion for improvement is welcome.

1/ Go to :

http://www.lojban.org/tiki/tiki-index.php?page=Parallel+2&bl#attachments

2/ Download data.tar.gz and parallel.py

3/ Unpack data.tar.gz, it should unpack as a directory called 
"parallel"

4/ Copy parallel.py to that directory

5/ Type "python parallel.py" in that directory, or read comments at 
beginning of parallel.py file

6/ Tell me if it works
