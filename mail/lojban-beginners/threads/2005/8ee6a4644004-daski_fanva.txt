No.

To compile a piece of software means to take a written
representation of the program (the source code) and turn it into
something you can actually run on your computer (the object code).

> I'm currently trying to build a Linux computer and get one of the
> various boot CDs to install on it, to no avail...

Linux is still pretty hard for a non-techie to deal with, IMO.

> Is it feasible to "compile" this dictionary for Palm OS?

No; they are different systems entirely, so the code for one won't
make any sense on the other.

On PalmOS, you can use SuperMemo as both a memorization program and
a word lookup program.

(the language the program is written in) on your PDA.  Run Dialect, open 
the source code file for daskifanva and then click File... Make Exe

only have an ipaq so that is the only one I can generate executables for
