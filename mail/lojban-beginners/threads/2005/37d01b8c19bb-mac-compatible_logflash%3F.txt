Many people are pretty keen on SuperMemo - 
http://www.lojban.org/tiki/tiki-index.php?page=Software&bl, but 
unfortunately it doesn't appear to have a Macintosh version.

Alternatively, I could motivate myself to finishing LearnLojban - which 
is written in Java and should run on a Mac with a bit of tweaking. At 
the moment, you'll need to be a programmer to use it. Umm... it's hidden 
on the Internet. I'll fix it up and release a newer version at some stage.

Also, I'd recommend using a PDA above using a laptop to learn from :-). 
PDA's are pretty handy when you're sitting on a train and don't have a 
book with you.
