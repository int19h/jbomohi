Very impressive!  One slight nitpick: your XHTML declares it to be written in 
the English language.  This line:

<html xmlns="http://www.w3.org/1999/xhtml" xml:lang="en" lang="en">

..should read:

<html xmlns="http://www.w3.org/1999/xhtml" xml:lang="jbo" lang="jbo">

In actual fact, there's really no need for XHTML, in HTML, the line would just 
be:

<html lang="jbo">

You have the same problem in your Atom feed.  This:

<feed xmlns="http://purl.org/atom/ns#" version="0.3" xml:lang="en-US">

...should be this:

<feed xmlns="http://purl.org/atom/ns#" version="0.3" xml:lang="jbo">

I'm not sure if you'll be able to change this or if it's a bug that Google 
have to fix though.

(Just in case you are tempted to change this too: the <!DOCTYPE line 
containing references to EN shouldn't be changed; this refers to the language 
the specification is written in, not the language your website is written 
in.)
