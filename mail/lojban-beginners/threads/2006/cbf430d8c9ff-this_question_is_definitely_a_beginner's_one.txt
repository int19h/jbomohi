How about

do pamoi le'i dotco prenu poi mi penmi

"You are the first from the set of german persons which I met"

The point is that {moi} creates a new selbri with the place structure
x1 pamoi x2 x3 = x1 is the first member of the set x2 ordered by the rule x3

I think it has meaning which differs from the wished
one (but I am not sure). Your sentence probably means
than among germans you are the first one (by some
unspecified quantity) and I met you.

Moreover, {poi} probably should select form the set
coming before {poi} subset which has property
mentioned after {poi}. And in the given sentence set
coming before {poi} has already only one element.

The jbofi'e parsing


   (0[do CU {<pa moi> <(1le'i [{dotco prenu} {poi <mi CU (2penmi VAU)2>
KU'O}] KU)1 VAU>}])0

seems to support my variant: the descriptor {le'i} extends to the whole tail
of the sentence, including the {poi} clause. The argument x2 of {pamoi}
is thus "the set of those germans, who I met", not just the set of some
germans, if I read it correctly.
