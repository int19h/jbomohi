Though, maybe, I am inventing a wheel, but, this discussion pushed me to 
write simple Mozilla search plugin for jvoblaste.

You can download it here: http:\\ratson.narod.ru

It is not a site, just page with several links on it, plugin is first link.

Currently, in order to install plugin, you should copy it to folder 
"searchplugins" in your Mozilla (Firefox) directory, in my case it is 
"C:\Program Files\Mozilla Firefox\searchplugins"; and then restart Mozilla.

This plugin is very draft (it took 15 minutes to write it), and any 
changes are welcome.
