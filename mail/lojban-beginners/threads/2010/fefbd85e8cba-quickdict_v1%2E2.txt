I like the launch vlasisku thing. As far as url shortcuts,
jbovlaste.lojban.org is the only one I can think of off the top of my head.

One error I did find, is that it doesn't find cmavo that begin with a vowel,
with or without the preceding ".". Also, it apparently can't handle any
cmavo clusters that aren't predefined.

Also, the close-reopen thing is nice, but it is a bit annoying to have it
move everytime - I would prefer that the window stay where I put it, at
least until I specifically tell it to close.
I like the configure settings option. It's not really a big deal, but it
would be nice to be able to configure the settings from within the program
itself - the always on top and enable vlasisku options would work perfectly
fine as checkmarkable options in the menu, since they are merely boolean,
and the close method option could be a submenu. For the hotkey, the only
thing I can think of is to have the option launch a subprocess that asks for
a single key input, similar to the Reminder message but closing at the press
of a (valid) key (which would also get rid of the guess work involving which
keys are able to be used as a hotkey as well as what their "name" is).

Integrating the configuration as above would also make restarting
automagical, since it would no doubt be a simple matter to code "alwaysontop
= !alwaysontop ; restart", etc.
