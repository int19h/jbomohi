DabbleDB has just made their web database service free for anyone who
allows their database to be public under a Creative Commons license.
Several months ago I made a reference database of Lojban words using
their free trial period, and now I've converted it to the free
version. It can be viewed at http://lojban.dabbledb.com/

There can be fifteen administrator users who create the data
structure, but nobody needs to have an account on the site just to add
content to the database. You can submit content with this private
code: 139748472 For instance, there is a list of fu'ivla which is
currently empty.

I have added a field to the gismu entries for the list of words
related to each gismu, which are links to the entries for those words.
This is the list preceded by "(cf." in the gismu list. However, I
don't want to copy and paste these lists out of the definition field
and into the cf field manually. Would someone be so kind as to create
a new delimited document of
http://www.lojban.org/publications/wordlists/gismu.txt starting a
column with (cf. as the starting delimiter? If you can omit that
delimiter as well as the commas and the closing parenthesis, that
would be great. Then I'll delete the current gismu database and
re-import it from your document.

There are two other dimensions along which I'd like to be able to
search the database, which would need to be done in this document. One
would be an additional column, into which is isolated the
square-bracketed content in the definition, if any. Also an additional
column into which is isolated any parenthetical content in the
definition. Please separate a single entry's multiple sets of
parenthesis or brackets with a space.

Please send it to matt.mattarn@gmail.com. Thanks!

-Eppcott
