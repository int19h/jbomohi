Sarah Leach: you probably want to subscribe to tlhingan-hol instead.

The rest of you: Robin runs both the Klingon and Lojban mailing lists. http://www.kli.org/tlhIngan-Hol/ has a prominent link to http://www.digitalkingdom.org/cgi-bin/lsg2.cgi, which is used to join any mailing list run from lojban.org, including this one.

I presume the source of the confusion is that the name of the Klingon mailing list is "tlhingan-hol" (not immediately recognizable to someone who doesn't know any Klingon), while this mailing list is the only in the list that contains the word "beginners". This is poor usability, and should be fixed. Might it not be possible to make Ecartis display only the Klingon-related lists to people arriving from kli.org?
