As far as I understand the morphology, yes, it is valid, as long as the other
rules for {fu'ivla} are followed (e.g., that first CC must be an initial
consonant pair).  Except when {rafsi fu'ivla} come into play, no {brivla} that
contains four consonants in a row can ever be a {lujvo}, a {gismu}, or a
combination of {lujvo}, {gismu}, and/or {cmavo}, nor can it ever fail the
{slinku'i} test.

I consider it to be valid if the first CC is an initial consonant pair, the 
other CCs are valid consonant pairs, and there is no "n[t|d][c|j|s|z]" in it. 
I'm not sure of xorxes's rules, but I think he would additionally require 
that the last CCC belong to a restricted set. So he would allow "slabjgle" 
but not "tramtsto", whereas I would allow them both.

Even with rafsi fu'ivla, a lujvo can't have four consonants in a row unless 
they are in one of the component fu'ivla. Any rafsi ending in two or more 
consonants must have "y" after it if it's followed by another rafsi.

Is there a particular fu'ivla you have in mind?

>> > Is a fu'ivla of form "CCVCCCCV" valid?

Yes, provided the initial CC is a valid initial and the CCCC is a valid cluster.

>> > I couldn't find it on the "nice fu'ivla forms" list.

The definition of "nice" given in that page is: "nice fu'ivla forms
are those forms that don't contain VVV, CC/C or CCCC groups, which can
never appear in lujvo, and start with one or two consonants."

That's not exactly how I would define "nice" forms today, but the four
consonant cluster is the reason that form is not on the list. (Today I
would define "nice" as any fu'ivla that does not contain syllabic
consonants.)

> I'm not sure of xorxes's rules, but I think he would additionally require
> that the last CCC belong to a restricted set.

I would require that the last CCC be a valid initial, or that the
first CC of the CCCC cluster be a valid syllable. In other words,
"CCVCCCCV" has to consist of valid syllables, either two syllables
CCVC-CCCV or three CCV-CC-CCV.

> So he would allow "slabjgle"
> but not "tramtsto", whereas I would allow them both.

Right, because I don't take "tsto" to be a valid syllable (nor "mt",
nor "tramt"). "tratmsto" would be acceptable: tra-tm-sto.

fu'ivla and cmevla, but then CLL has at least one cmevla example with
