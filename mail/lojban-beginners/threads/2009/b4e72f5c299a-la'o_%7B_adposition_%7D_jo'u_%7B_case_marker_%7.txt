pilno tu'a lo sumsu'a ( gy. place structure .gy ) .i mu'a fliba morji
lo du'u lo mu moi pe { klama } cu du ma kau .i zu'u lo jbobau cu friti
lo xamgu .i fau ku ka'e pilno { sepi'o } lo nu cusku tu'a lo mu moi pe
{ klama } .i mu'a

 klama sepi'o lo karce = klama fu lo karce

.i ji'a

 klama ve'a lo dargu = klama fo lo dargu
 klama ra'i lo zdani = klama fi lo zdani
 klama fa'a lo zarci = klama fe lo zarci

.i panra lo ingli valsi po'u { by } fa'u { via } fa'u { from } fa'u {
to } .i seki'ubo pe'i ka'e ctuca lo cfacilre lo du'u seva'u panra so'o
na'e jbobau sumtcita ( gy. adposition, preposition, postposition .gy )
