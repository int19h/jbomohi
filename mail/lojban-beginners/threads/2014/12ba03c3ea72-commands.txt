I've never really liked the word "ko", perhaps because i don't fully 
understand it. I know it means "the party addressed" while changing the 
sentence from an assertion to a command to make the sentence true. But what 
if i'm a member of the party addressed? How do i command mi'o or ma'a? I 
thought that some UI cmavo that turns a sentence into a command would work 
better, since commands don't always involve the addressee.

How do i tell someone to make "le gerku cu zvati lo ri gerzda" true?

> I've never really liked the word "ko", perhaps because i don't fully

> if i'm a member of the party addressed? How do i command mi'o or ma'a?

According to official Lojban: {do ma'a ko klama}.

And there is an experimental cmavo {ko'oi} of selma'o UI so that
{ko = do ko'oi} and {mi'o ko'oi klama} however, {mi'o e'u klama} is
probably what you want in most cases.

I thought that some UI cmavo that turns a sentence into a command would
> work better, since commands don't always involve the addressee.
>
> How do i tell someone to make "le gerku cu zvati lo ri gerzda" true?
>

gau ko lo gerku cu zvati lo gerzda be ri = Make it so that the dog is
inside its doghouse.
