# Prototype notes (research phase, 2026-08-26)

The prototype that produced the numbers in `REPORT.md` lives in the untracked
scratch directory `tmp/fable/proto/` on the machine where the research was done
(`uv run` inside it; API keys are read from `~/git/jguvi-api-keys.md`). It is
not part of the repository; this note records what it did so the tools can
reproduce it (`doc/SPEC.md §8`).

- `chunk_wiki.py`, `chunk_irc.py`, `chunk_mail.py` — unit extraction per source
  (the rules in `doc/SPEC.md §5.1` are these, cleaned up). Outputs
  `data/chunks_<source>.jsonl` with `id, source, date, ctx, text, tokens`.
- `gen_queries.py` — synthetic evaluation queries (vague / keyed / paraphrase)
  generated by Claude from random units; `data/queries_<source>.jsonl`.
- `bench.py`, `bench_post.py` — retrieval benchmark: BM25 (rank-bm25) vs dense
  (OpenRouter embeddings, cached under `data/emb/`) vs RRF hybrids, per style
  and per source; results in `data/bench_*.json`.
- `index_lex.py`, `corpus.py` — Tantivy index over all ~210k units with an
  apostrophe-safe `jbo` field; `search()` and `read()` with neighbours.
- `agent.py` — the librarian loop (Claude Messages API, two tools `search` /
  `read`, prompt caching on every turn, cost metering, citation check);
  `data/agent_runs*.jsonl` holds the full answers, traces and usage for the
  questions in `../eval/questions.jsonl`.
- `verify.py` — fuzzy verbatim-quote verification against the cited units.
- `irc_gaps.py` — the inter-message gap statistics behind the IRC window rule.
- `token_counts.py` — cl100k token counts of the reference sources.

Key numbers are summarised in `REPORT.md §4` and `§8`.
