# doc/

- `SPEC.md` — the functional specification (normative; supersedes the research report where they differ).
- `research/` — the evidence base: `REPORT.md` (architecture research, prototype results, comparison with Codex's report), `data-survey.md` (local data inventory and parsing quirks), `domain-data-handling.md` (verified online sources), `retrieval-sota.md`, `embeddings-landscape.md`, `agent-harness.md`, `codex-architecture-research.md`, `proto-notes.md`.
- `eval/` — evaluation assets: `questions.jsonl` (realistic librarian questions by category; rubrics to be added).
- `future/` — deferred design (indexes, a librarian service, interfaces); not a backlog.
- `decisions/` — dated decision records for gates and adjudicated open questions (one file per decision).
- `issues/` — numbered issue drafts until the GitHub tracker exists.
