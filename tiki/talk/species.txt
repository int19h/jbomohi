Herewith some definitions, axioms, and theorems (I am not always sure which is which), all open to revision:

For every property P there is a set S(P) = {x : Px}

For every set s, there is a property P(s) such that s = {x :P(s)x}

So, s = M(P(s)) and P = P(M(P))

If P(s) = P(t), then s = t (but not conversely!)

For every property P, there is a property â€“P (the complement of P, intuitively the property everything has that is not P: some of its features are spelled out below)

P is pervaded by Q iff P overlaps Q and P does not overlap â€“Q

i is an individual concept iff i is a property that pervades no other property.  (i may overlap and number of other property and â€“ with at most one exception â€“ does.)

For every individual concept i and every property P, if i overlaps P, then it is not the case that i overlaps â€“P.
So, trivially, if i overlaps P, i is pervaded by P.


For all objects x and properties P, 0 < H (x, P) < 1  (â€œhow good a P x isâ€)
For every property P, 0 < A (P) < 1 (â€œHow good is good enoughâ€)

For all x, P, x is P iff H(x,P) > A(P)

For all x, P, x is a member of S(P) iff x is P

For all x, sets s, E(x,s) = H(x, P(s))  (so something is in a set  S(P) exactly as far as it is a good P)

For every set s, A(s) = A(P(s))

For every x, set s, x is a member of s iff E(x,s) > A(s)

P mingles with Q to degree n just in case there are n x such x is P and x is Q  (or is a member of S(P) and S(Q))

P mingles with Q iff for some n > 0, P mingles with Q to degree n

If P is pervaded by Q,  S(P) is included in S(Q)
If S(P) mingles with S(Q), then P overlaps Q

1-sum of 0 elements is 0
If 1-sum of n elements is m, then 1-sum n+1elements is m + the value of element n+1, if that sum is less than or equal to 1
If 1-sum of n elements is 1, then 1-sum of n+1 elements is 1

For every set s, there is a function fs such that the 1-sum of f(E(x,s)) for all x in s is 1  (but may get there sooner)

fs(m) > fs(n) just in case m > n
 
For every property P, 0 < G(P) < 1 (what it take to be generally true in S(P))

P intersects Q just in case the 1-sum for all x each in both P and Q of the products of fS(P)(E(x,S(P)) and fS(Q)(E(x,S(Q)) is greater or equal to G(P).  
(That is, some combination of good Ps that are good Qs or a lot more so-so Ps that are so-so Qs or somewhere in between for those which are good of one and so-so of the other).  
(This could be done without talking about sets and probably should be.)
(The function from the two membership relations to the final value may not be product, but that looks about right for now.)

H(x, I(x)) = 1

If I(a) overlaps P, then I(a) is pervaded by P


It should be noted that the values of G and A for particular properties (or sets) are
very dependent on the conditions of the utterances which are being evaluated; what is good enough for the bar may not be for the laboratory and so on
