## 2015-11-20T20:45:43Z — krtisfranks (comment 2612, on definition 68088)

Good start

I think that we need a way to specify conventions for interpretation of 
mathematical expressions in general; we should be able to specify the order
of operations by name (example: "PEMDAS" refers to a fairly standard 
version of the order of operations for basic arithmetic of complex 
numbers), the order of reading, etc. This is a good start, but the grammar 
needs to be able to accept any amount of free modification to 
interpretation procedures. In fact, this concept should be extended beyond 
mathematics so that one can specify which version of Lojban grammar they 
are using at any given time.
