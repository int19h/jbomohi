Expand from sumti to Any Construct?

I limited the copying function of this word to only select/read from the 
ordered set of sumti in the discourse/text/utterance. The paste feature is 
more universal (it can be used anywhere where seltau may appear, as long as
an explicit tertau follows it). I did this because the functionality is 
easier to implement and back-counting is far more clear this way. Should we
expand the consideration scope of the copying mechanism (for this word or 
in another, similar word) to look at any construct which has a seltau? If 
so, how does one distinguish and back-count through selbri, relative 
clauses, BE links, and everything else (in addition to full sumti).
