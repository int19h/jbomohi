Dimensionality

I propose that we extend the semantics of this word so as to include 
n-cells (n-orthotopes). The two arguments would be points in n-space X 
which may be expressed/represented with respect to a given basis as a = 
(a_1, ..., a_n) and b = (b_1, ..., b_n). Then the "interval" formed is the 
n-cell that consists of the set of all points x = (x_1, ..., x_n) in X such
that for each i which is a natural number less than or equal to n, a_i  < 
x_i < b_i, where the meaning/strictness of each of the two instances of "<"
can be determined by context and/or by use of {ga'o} and {ke'i}. X would be
determined by context.
