("za'u no me'i ro" is a string of digits which may mean that it gets
interpreted differently in meaning. Lojban for the most part does not
specify how to interpret digit strings. I would expect the interpretation
of this one or similar things to approximate this meaning, but I cannot
guarantee it. We can guarantee that it, in the standard Lojban way with
vague numbers, represents some value which is strictly between 0 and
'all', which we can express via a bridi. Note, btw and as an example, that
it is not necessarily clear how to interpret strings with multiple "za'u"s
or "me'i"s, which illustrates some of the pitfalls of working with digit
strings which do not have a predetermined interpretation scheme (unlike
"pa re ci", which must be "123" in the given base)).
