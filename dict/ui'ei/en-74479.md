Convert arbitrary bridi to UI with the grammar of {sei}.

## Notes

Converts bridis to UI; shorthand for «.ui {ma'o'ei}».  For a grammar closer to sumti rather than SEI, see also {ki'ai}, which uses COI2 rather than SEI, which can convert cmevla, selbri, and zoi quotes; this permits the shorter version of e.g. «ki'ai .xm. mi pensi» rather than e.g. «.ui'ei me la .xm. mi pensi».  For conversion to selbri, see {tai'i}.  See also {ju'a'ei} for nonce evidentials (e.g. «ju'a'ei simlu» for «si'au» (‘it seems …’)).  Note that after SEI, selbri auto-terminate with {se'u} once a sumti is found, unless it is attached with {be} or {bei} (or {bei'i}); however, {bei'e} may be used after a SEI cmavo to still apply the following sumti, with effectively automatic {bei'i} application.  For converting bridi to arbitrary existing grammar, see {ma'o'ei}.
