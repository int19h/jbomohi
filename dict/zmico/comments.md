## 2014-05-30T04:38:58Z — krtisfranks (comment 1151)

List of words that belong to the set of all zmico

The set of {zmico} is currently bipartite; it is also a subset of the set
of {cmavo}, and currently intersects nonemptily four selma'o. One subset
is the set of {gafyzmico} (default specification modifiers), the other is
the set of {sumyzmico} (default-value-referencing pro-sumti); these two
subsets have empty intersection and in fact, currently, partition the set
of zmico. The set of gafyzmico intersects nonemptily and nonfully selma'o
DAhO (elements of this intersection are additionally discursives as a
result), intersects nonemptily but currently fully selma'o DEhAU (although
there is no reason to suspect that this situation will long endure; in
fact, I am not even sure that selma'o DEhAU may not be subsumed by some
other selma'o), and intersects nonemptily but currently fully selma'o
DEhAI. Currently, selma'o DEhAU and DEhAI are proper nonempty subset of
the set of gafyzmico. The set of sumyzmico is currently a proper nonempty
subset of selma'o KOhA7; as such, they are all pro-sumti. The list of all
members of the set of zmico follows, by taxonomy.

zmico
 /gafyzmico
  /gafyzmico-intersect-DAhO:  {do'ai}, {dai'o}
  /gafyzmico-intersect-DEhAU: {de'au}, {de'oi},
			      {dau'a}, {doi'a}
  /gafyzmico-intersect-DEhAI: {de'ai}
 /sumyzmico
  /sumyzmico-intersect-KOhA7: {di'au}, {di'oi}, {di'ei}
.
