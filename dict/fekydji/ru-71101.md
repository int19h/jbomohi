$x_1=f_1=d_1$ испытывает маниакальное влечение по отношению к $x_2=d_2$

## Notes

Для обозначения патологических стремлений, болезненных влечений, вызванных психическими расстройствами, и тому подобным. Образовано по модели ({fekcni}->{fekydji}). $d_3$ выражается с помощью {mu'i}. Для описания болезней, ключевым проявлением которых является описываемое влечение, используется модель ({fekydji} -> {fekydjibi'a}). Для формирования подкласса влечения на основании объекта влечения используется модель ({fekydji} -> {glefekydji}).
