## 2015-01-25T16:14:27Z — Ilmen (comment 1649, on definition 64293, in reply to 1647)

Re: Sounds like “minde”

Wuzzy wrote:
> I wonder how this word is supposed to differ from “{minde}”.
> The definitions seem to be equivalent, so is “{koinde}” a synonym of
> “{minde}”?

This predicate is intended to be a predicate form of {ko'oi}, which has a
broader meaning that commands/orders, so I'd say it is a superset of
{minde}.

As suggested by Xorxes, I've added several -nde fu'ivla based on the .e'V
series of attitudinals (such as .{e'ende}), with the same place structure.
{koinde} is to be part of this series.
