$x_1$ is a form of ornamentation arranged cylindrically and which is meant to be viewed so that its axis is collapsed to a point (in perpendicular cross-section), which adorns $x_2$

## Notes

Uses experimental gismu: {clenu}, {kukru}, {paxra}. This is opposed to tile/flat/two-dimensional art (such as paintings) and/or art which decorates an object and is meant to be viewed along the sides of that object in profile (such as on Greek urns, etc.).
