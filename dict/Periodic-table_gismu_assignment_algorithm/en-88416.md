**Periodic-table gismu assignment algorithm**

The goal is a five-letter Lojban gismu for each of the 118 elements. Official gismu that already name the element are kept. Every other element gets a newly proposed form that is a legal gismu, contains the element abbreviation as a skip-gram, fits the Latin (or English) name as well as possible, and does not gimka-clash with official gismu, experimental gismu, or another proposal already chosen.

***

**1. Inputs**

* Element list: atomic number, symbol, English name, Latin name, discovery year (Wikipedia timeline; BCE as a negative year).
* Official element gismu (kept as-is): H `cidro`, C `tabno`, N `trano`, O `kijno`, S `sliri`, Na `sodna`, Cl `kliru`, Ne `navni`, Fe `tirse`, Ni `nikle`, Cu `tunka`, Zn `zinki`, Ag `rijno`, Sn `tinci`, Au `solji`, Hg `margu`, Pb `cnisa`.
* `gismu.tsv` and `experimental\_gismu.tsv` as frozen clash sets (exact forms must not be reused; gimka similarity is also forbidden).
* Curated element lujvo from `lujvo.tsv` (recorded, not used as the gismu).

***

**2. Letter mapping**

**Element symbol** (no `ph`/`th`/`ch` collapse):

| letter                         | Lojban |
| ------------------------------ | ------ |
| h                              | x      |
| w                              | v      |
| y                              | i      |
| q                              | k      |
| other `bcdfgjklmnprstvxzaeiou` | itself |

Example: Mg → `mg`, He → `xe`, Y → `i`, W → `v`.

**Latin / English name** (lojbanization):

1. Lowercase.
2. Optionally collapse digraphs: `ph`→`f`, `th`→`t`, `ch`→`k` (tried both on and off).
3. `h`→`x` or drop `h` (tried both).
4. `w`→`v`, `y`→`i`, `q`→`k`.
5. Drop any other character.
6. Collapse consecutive duplicate letters (`ll`→`l`, `nn`→`n`).

Example: beryllium → `berilium`; molybdenum → `molibdenum`.

Each name yields one or more letter-strings. **Latin spellings are used for scoring.** English and extra names are recorded but do not break ties.

***

**3. Legal gismu shape**

A candidate must be five letters, each in `bcdfgjklmnprstvxzaeiou`, and either:

* **CVCCV**, with a legal *medial* cluster (not a geminate, not mixed voiced/unvoiced, not two sibilants from `cjsz`, not `cx`/`kx`/`xc`/`xk`/`mz`), or
* **CCVCV**, with a legal *initial* cluster from the standard Lojban initial-pair list.

***

**4. Abbreviation filter (who may be a candidate)**

Let `seq` be the lojbanized symbol.

A legal gismu `w` is a candidate for that element only if:

1. The letters of `seq` appear **in order** in `w` (gaps allowed). This is the abbrev skip-gram. A contiguous copy of `seq` also counts.
2. If `seq` **starts with a consonant**, `w` must **start with that same letter**.
3. If `seq` **starts with a vowel**, rule 2 is dropped (a gismu cannot begin with a vowel). Rule 1 still applies.

Examples: Mg requires a form starting with `m` that contains `m` then later `g`. Al (`al`) may start with any consonant, but must contain `a` then `l` in order.

***

**5. Score of one (gismu, Latin-string) pair**

Higher is better. Components, in the order they are added:

**5.1 Longest Latin n-gram**

Longest skip-gram of the Latin string that occurs as a skip-gram of the gismu.

Score += that length (excluded non-matching letters within the skip-gram)

To compute that one skip-gram score,

1. Try the real gismu and Latin strings.

2. Additionally add the same score but on copies with `v`→`u`, `w`→`u`, and `h` deleted; each replacement leads to `score -= 0.3` for this mapped score.

Choose the highest score between 1. and 2. Don't sum them up.

The candidate gismu itself is not edited.

**5.2 Prefix n-gram bonus**

Score += the length of the longest match between the prefix (start substring) of the Latin string and the prefix of the gismu. Letter replacements are not used here.

**5.3 Abbrev skip-gram or n-gram**

If the letters of `seq` occur in order in the gismu (contiguous or gapped), score += **5**, at most once. A one-letter abbrev gets this bonus from a bare occurrence of that letter.

Every two-letter (or longer) abbrev that already passed the candidate filter gets this bonus; a gapped match (`m…g` in `magne`) counts the same as a contiguous pair (`mg` in `mamge`).

**5.3 Tie-breakers after the numeric score**

Compared in this order:

1. Length of the longest **contiguous** Latin prefix that occurs as a substring of the gismu (how much of the start of the Latin name appears contiguously in the gismu).
2. Prefer a gismu that starts with a CC cluster (`CCVCV` over `CVCCV`).
3. After deleting every `x` from the gismu and every `h` from the Latin string, number of **contiguous 4-grams**: how many 4-letter substrings of that Latin string occur as substrings of that gismu.
4. The same count for **contiguous 3-grams** on those stripped strings.
5. Number of **3-letter** Latin skip-grams: how many contiguous 3-letter pieces of the (unstripped) Latin string occur in order in the gismu (gaps allowed).
6. Number of **2-letter** Latin skip-grams, counted the same way.
7. Repeat 5 after deleting every `x` from the gismu and every `h` from the Latin string.
8. Repeat 6 on those same stripped strings.
9. If the Latin string **starts with a vowel**, prefer a gismu that starts with `j`. If it starts with a consonant, this step does not distinguish candidates.

Implementation note: ranks are stored as tuples of negated scores so that ordinary ascending sort picks the best form.

***

**6. Clash test (gimka)**

A candidate is illegal if it gimka-matches any frozen word or any already-assigned proposal.

Two five-letter forms clash if either:

* they share a **4-letter stem** (first four letters of one equal the first four of the other), or
* they differ in **exactly one position**, and those two letters are a Lojban similarity pair (`b`/`p`/`v`, `c`/`j`/`s`, `d`/`t`, `g`/`k`/`x`, `l`/`r`, `m`/`n`, etc.).

Official and experimental dictionary words are frozen: they can never be assigned, and nothing similar to them may be assigned.

***

**7. Assignment in discovery-year order**

Official gismu are kept first (they freeze those forms for everyone).

Then, for every remaining element, in **historical discovery order** (earlier year first; same year uses smaller atomic number):

1. List all legal candidates that pass the abbrev filter, sorted by the rank in section 5.
2. Assign that element’s **best remaining** candidate that is not taken and does not gimka-clash with frozen words or with proposals already assigned.
3. That form is taken: later (more recently discovered) elements may not use it or anything that gimka-clashes with it.
4. If an element runs out of clash-free candidates, it is marked failed.

So magnesium (1755) is assigned before manganese (1770) and can keep a `magn-` stem; manganese then takes the next clash-free form.

***

**8. Outputs**

Each element record includes at least: Z, symbol, English, Latin, discovery year, lojbanized symbol, official gismu and/or attested lujvo if any, chosen gismu, status (`official-gismu` / `proposed-gismu` / `failed`), abbrev letter positions, the Latin string that scored best, and notes when official forms omit the symbol letters.

For proposed gismu, `candidates` lists **same-score tie-breakers** only (other legal forms with the same rank tuple as the winner, comma-separated), not the full candidate list. A form is omitted from that list if it is an official or experimental gismu or **gimka-clashes** with one (so e.g. `rirxo` is not listed next to a rhodium proposal, because it clashes with official `rirxe`).

**9. Worked sketch**

**Magnesium** (`mg`, Latin `magnesium`):

* Filter: must start with `m`, contain `m` then `g`.
* `magne` has longest skip-gram 5 (`m-a-g-n-e`) and shared prefix length 5 with `magnesium`, plus +5 for the gapped abbrev `m…g`.
* `mamge` also gets +5 for abbrev `mg` (contiguous), but a shorter Latin skip-gram.

**Manganese** (`mn`, Latin `manganum`) is assigned later (1770) than magnesium (1755), so it cannot take a stem already frozen by magnesium.

**Aluminium** (`al`): gismu cannot start with `a`, so the onset rule is waived; the form must still contain `a` then `l`.
