Notation

In math, it is often the case that for a set X and and function for defined
on at least X, f(X) is used in order to denote the set of all results of f 
being applied to elements of X (thst is, the image of X under f). However, 
f is a function defined on X, not on the powerset of X; thus, this is 
technically an abuse of notation. Lojban should avoid such problems by 
utilizing this (or possibly another similar) word.


## 2015-11-28T20:25:23Z — krtisfranks (comment 2628, on definition 63936)

Output

The operator should be defined on the Cartesian product of the sets that 
are operands (in the appropriate order). If the operator is undefined for 
one tuple of elements, there is no consequence (just ignore the problem and
move on).




If the operator is addition (especially of vectors), this produces a 
Minkowski sum.
