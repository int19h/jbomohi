binary mekso operator: Let the inputs $X_1$ and $X_2$ be sets in the same universal set $O$; then the result of this operator applied to them is $X_{1}^{c}  \cap X_{2}^{c}$, where for any $A \subseteq O, A^{c} = O \setminus A$.

## Notes

This is a dual to {xa'ei'o} and largely has the same properties; only one of them is needed in any operator system.
