$x_1$ is emitted/reflected light that measures to be $x_2$ magnitudes in luminous brightness, on scale (si'o)/using reference value/under system/according to definition $x_3$, in logarithmic base $x_4$ (default: decimal (10))

## Notes

Wavelength is specified in x1; it is improper to submit an object as the sumti for x1. The type of magnitude (absolute, apparent, etc.) must be specified by tanru or lujvo. x2 must be a pure number (dimensionless). x3 should specify a reference emission and the associated reference value in magnitudes, the meaning of a change by 1 magnitude, and the direction of increasing brightness (traditionally: toward negative infinity); magnitude is defined for all real numbers. See also: {cmagnitude}.
