$x_1$ is a laundry machine/washing machine

## Notes

Intended to replace {taflumca'a}, which is imprecisely defined: per official gismu place structure, a washing machine is properly considered {minji} ("machine", a device which performs its function automatically, e.g. {lafmi'i} "elevator/lift") rather than {cabra} ("apparatus", a device which has some automatic/mechanical component but must be held or manipulated in some way while in use, e.g. {lafca'a} "jack").
