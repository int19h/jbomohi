Word choice

I actually think that the "alphabetic order" words, such as the one here
or linked in its notes, should be mapped to the same word + "(y)pors",
unless they already end with "pors" or similar. So, for example, the
definitions and descriptions associated with ".abeced" should instead be
assigned to ".abecedypors". The words here should be something more like
"the script used for ..."; so, ".abeced" would become defined as something
like ~"the basic Latin script or the script used for the Latin language,
or derivatives thereof, or similar scripts". (Thus, the result would not
be very distinct from the ISO script zevla but would be a cmevla and might
be easier to remember).

I have kept the current definition scheme (referencing the alphabetic
order meaning) for consistency with the other words which were similarly
defined.

P.S.: I think that we should replace "alphabetic order" with
"alphabetic/characterwise lexicographic order" or something similar.
