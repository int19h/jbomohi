converts bridi into nonce modal/sumti tag clause sharing common places with the main clause

## Notes

1. The first place containing abstraction (if present in the predicate of the subordinate clause) is automatically applied to the whole bridi if not explicitly defined otherwise 2. If the first place is an object it's applied to the first place of the bridi. See also {fi'o}
