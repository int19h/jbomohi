Warning: Looks like stage-3 but is stage-4 actually

This word is legit but just a side note for the future:
You may think this word is a stage-3 because of “zgi”. But a short
rafsi only makes it a stage-3 fu'ivla if it is in the form
“consonant-vowel-consonant”. So this word is actually a stage-4
fu'ivla.
I created “{zgikrkumbia}” which means the same thing. It uses a
4-letter rafsi and is a stage-3 fu'ivla.

Don’t panic, this is just a friendly side note by me. I stay neutral on
this word and don’t vote.
