$x_1$ is a musical interval of size $x_2$ in tuning system $x_3$.

## Notes

The x1 place will usually accept ratios, but can also accept me'o + interval class, so e.g. "me'o me'i xa" can refer to a minor sixth just as well as "li bi fi'u mu". The x2 place refers to a size by some standard, usually cent measure.
