$x_1$ is a rafybri relation made using rafsi.

## Notes

Usually to refer to $x_1$, $x_2$... of the original relation either -{jve}- (for $x_1$),-{zve}- (for $x_2$), -{zvi}- (for $x_3$), -{zvo}- (for $x_4$), -{zvu}- (for $x_5$) system is used, or the system with -{faf}-, -{fef}-, -{fif}-, -{fof}-, -{fuf}-.
