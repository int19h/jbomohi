Reference frame

If any gismu have a sumti slot for 'in frame of reference', then this one 
should. I know that we can specify that via "{ma'i}", but specification of 
the frame of reference is inherent to and important for the understanding 
of simultaneity (confer: Special Relativity). There is no universal sense 
to simultaneity; the frame of reference MUST be specified somehow.

Of course, gismu which are very closely related to "cabna" (such "{balvi}",
"{purci}", and "{zvati}"), as well as most lujvo formed partially from this
word, could and usually should have this same sumti slot added to their 
definitions for the same reason.
