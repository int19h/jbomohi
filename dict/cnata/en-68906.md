$x_1$ is a logical 'if-else' (ternary conditional) statement saying that if $x_2$ is true, then $x_3$ is true (or performed), but otherwise/else (if $x_2$ is not true, then) $x_4$ is true (or performed).

## Notes

This word is like {kanxe} but for .{ifle}. See also: {sigda}.
